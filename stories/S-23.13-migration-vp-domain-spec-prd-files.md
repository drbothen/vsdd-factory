# S-23.13: Corpus migration — VP files (8) + domain-spec files (2) + PRD (1) document classes

## Narrative

- **As a** state-manager/consistency-validator executing ADR-045's mechanical corpus migration
- **I want** to run the S-23.02 codemod across the three smallest document classes in ADR-045's
  corpus scan — 8 individual VP files, 2 domain-spec files, and the single PRD file — completing
  full coverage of all 6 document classes named in ADR-045
- **So that** the entire ~3,074-live-pin / 156-file / 6-document-class migration scope ADR-045
  quantifies is fully closed, with no document class left un-migrated

## Context / Problem Statement

ADR-045 §Consequences, Negative/Trade-offs names 8 VP files, 2 domain-spec files, and 1 PRD file
as the three smallest document classes in the corpus scan (11 files total). Because each class is
small, this story combines all three into one story, but — per TD-VSDD-053 and ADR-045 §Migration
Plan Phase A step 5's "one atomic commit per document class" — the three classes are still
committed as three separate atomic commits (a story is a container of related work, not a single
commit itself; this mirrors the multi-task-multi-commit shape used implicitly by S-23.06..S-23.12
whenever a sidecar-regeneration commit accompanies the primary migration commit).

## Acceptance Criteria

### AC-001
Running the codemod in `--dry-run` mode against the 8 individual VP files (`.factory/specs/verification-properties/VP-*.md`,
excluding `VP-INDEX.md`, migrated in S-23.09) produces a diff report reviewed before apply.
(traces to ADR-045 §Migration Plan Phase A step 5; S-23.02 AC-006/AC-007)

### AC-002
Running the codemod in `--dry-run` mode against the 2 domain-spec files produces a diff report
reviewed before apply. (traces to ADR-045 §Migration Plan Phase A step 5)

### AC-003
Running the codemod in `--dry-run` mode against the single PRD file produces a diff report
reviewed before apply. (traces to ADR-045 §Migration Plan Phase A step 5)

### AC-004
Each of the three document classes is committed separately: one atomic commit for the 8 VP
files, one atomic commit for the 2 domain-spec files, one atomic commit for the PRD file — three
commits total, none combined, per TD-VSDD-053's "one atomic commit per document class." (traces
to ADR-045 §Migration Plan Phase A step 5, "one atomic commit per document class to respect
TD-VSDD-053")

### AC-005
None of the three commits modifies `modified:`/`last_amended:`/`[Prior:]`/`## Changelog` content
in any of the 11 files. (traces to S-23.01 AC-001)

### AC-006
Post-commit (all three), S-23.03's guard and S-23.05's extended parity gate pass against all 11
migrated files with zero findings. (traces to S-23.03 AC-001/AC-003; S-23.05 AC-001)

### AC-007 (negative control)
Post-commit, a targeted grep for live-section inline version pins across all 11 files (VP files +
domain-spec files + PRD) returns zero matches. This is also the FULL-CORPUS closure check for
ADR-045's named 6-document-class scope: combined with S-23.06..S-23.12's negative-control results,
this confirms every one of the 6 named document classes (stories, behavioral-contracts,
architecture, VPs, domain-spec, prd) — plus the 4 INDEX files — is fully migrated. (traces to
ADR-045 §Consequences Positive, "Cohort re-anchoring eliminated by construction"; ADR-045
§Consequences Negative/Trade-offs, 6-document-class enumeration)
