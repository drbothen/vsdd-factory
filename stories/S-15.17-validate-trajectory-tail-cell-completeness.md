## Narrative

- **As a** engine-discipline cycle operating across F5 pass boundaries (including multi-week pauses)
- **I want** trajectory_tail per-cell presence mechanically enforced across all D-453(d) canonical-mapping-table prescribed sites at PostToolUse write time
- **So that** the per-cell granularity discipline codified in D-454(a) cannot silently degrade during cycle pauses, preventing META-LEVEL-30 route (b) recurrence (codified-without-runtime-gate-permits-silent-degradation-over-time)

## Why This Exists

**F5 pass-75 finding ADV-EDP1-P75-HIGH-002** found that after a 14-day F5 pause, only 2 of the 9
mechanically-checkable D-453(d) prescribed sites for `trajectory_tail` carried the canonical tail
value. D-454(a) codified per-cell granularity discipline at the story (Dim-2 attestation) level,
but codification as a prose narrative check does not prevent silent degradation between passes.

**The structural escape hatch** is META-LEVEL-30 route (b): "codified-without-runtime-gate-permits-
silent-degradation-over-time." The adversary correctly identified that prose Dim-2 attestation
(Section 11 Step 3 narrative check counting ONE cell, not checking all 9) cannot enforce the
discipline at write time. Each STATE.md or cycle artifact edit that omits the trajectory_tail from
a prescribed cell succeeds without detection.

**D-453(d) canonical mapping table** (decision-log.md appendix) prescribes 11 sites for
`trajectory_tail`. Of these, 9 are mechanically checkable via PostToolUse on the artifact files that
contain them:

| Site | Document | Mechanically Checkable |
|------|----------|----------------------|
| STATE.md frontmatter `current_step` | STATE.md | Yes |
| STATE.md Last Updated cell | STATE.md | Yes |
| STATE.md Phase Progress rows (latest pass) | STATE.md | Yes |
| STATE.md Concurrent Cycles row | STATE.md | Yes |
| STATE.md Session Resume Section 1 | STATE.md | Yes |
| INDEX.md Convergence Status row | INDEX.md | Yes |
| INDEX.md adversarial-review summary-table rows (latest pass) | INDEX.md | Yes |
| burst-log latest-pass Dim-7 (Attestation) | burst-log.md | Yes |
| lessons.md latest-lesson trend-table | lessons.md | Yes |
| decision-log.md trajectory-bearing rows | decision-log.md | Advisory only (sparse; not every row) |
| adv-cycle-pass-*.md frontmatter trajectory_tail field | adv-cycle-pass-*.md | Out-of-scope (written by adversary, not by state-manager) |

This story implements a WASM hook that checks the 9 mechanically-enforceable sites at PostToolUse
on edits to the relevant `.factory/cycles/` and `.factory/STATE.md` files.

### Anticipated Invariants (for PO authorship guidance)

1. Hook NEVER writes any file (read-only PostToolUse validator).
2. Hook fires PostToolUse only — signals AFTER the write has completed.
3. Path-component-strict: target file detection uses `Path::new(file_path).file_name()` comparison
   for single-basename targets (STATE.md, INDEX.md, burst-log.md, lessons.md). Path suffix matching
   for cycle-namespaced files. `ends_with` on full path strings MUST NOT be used for basename checks.
4. Trajectory_tail pattern: canonical arrow-sequence regex `(→[0-9]+){4}` (LENGTH=4 per D-433(e)).
   A cell is "present" if the extracted section/field contains at least one match.
5. STATE.md checks (sites 1-5): Blocking severity (HIGH findings per D-411(a)) — these 5 cells are
   the primary STATE.md trajectory_tail sites and their omission has historically caused
   ADV-EDP1-P75-HIGH-002 class findings.
6. Non-STATE.md checks (sites 6-9): Advisory severity — emit log_warn + Continue (not Block); these
   cells are written by the same state-manager burst but are in separate files.
7. `max_bytes = 524288` (512 KiB) on ALL `host::read_file` calls (META-LEVEL-24 prevention).
8. All violations across all STATE.md sites cascade-reported in a single Block (schema-violation
   cascade invariant per BC-5.39.008 precedent).
9. No `HookResult::Advisory` variant exists in vsdd-hook-sdk — advisory behavior is
   `HookResult::Continue` + `host::log_warn`.
10. `host::read_file` HostError for any target file → Continue + log_warn (fail-open).
11. All byte-index slice expressions on content strings MUST use `is_char_boundary()` guards.

  **Trajectory_tail pattern (canonical LENGTH=4 per D-433(e)):**

  ```rust
  use regex::Regex;  // or manual pattern check if regex is not a workspace dep

  fn has_trajectory_tail(text: &str) -> bool {
      // Canonical form: (→[0-9]+){4} — LENGTH exactly 4
      // Accept: →9→9→9→9 (pass), →9→9→9 (fail — length 3)
      let mut arrows = 0u8;
      let mut i = 0;
      let bytes = text.as_bytes();
      while i < bytes.len() {
          if bytes[i..].starts_with("→".as_bytes()) {
              arrows += 1;
              i += "→".len();
              // skip digits
              while i < bytes.len() && bytes[i].is_ascii_digit() { i += 1; }
          } else {
              if arrows >= 4 { return true; }
              arrows = 0;
              i += 1;
          }
      }
      arrows >= 4
  }
  // NOTE: Implementer MUST verify the approach correctly handles multi-byte UTF-8 boundary safety.
  // Use is_char_boundary() guards on any slice operations per BC invariant 11.
  ```

  ```rust
  pub fn on_post_tool_use(payload: HookPayload) -> HookResult {
      let file_path = match payload.tool_input.get("file_path").and_then(|v| v.as_str()) {
          Some(p) => p,
          None => return HookResult::Continue,
      };
      let arm = match target_arm(file_path) {
          Some(a) => a,
          None => return HookResult::Continue,
      };
      let content = match host::read_file(file_path, MAX_BYTES, 2000) {
          Ok(c) => c,
          Err(e) => {
              host::log_warn(&format!(
                  "validate-trajectory-tail-cell-completeness: read failed for {}: {:?}; skipping",
                  file_path, e
              ));
              return HookResult::Continue;
          }
      };
      match arm {
          TargetArm::State => {
              let missing = check_state_md(&content);
              if missing.is_empty() {
                  HookResult::Continue
              } else {
                  let sites = missing.iter().map(|s| format!("  - {}", s.site_name))
                      .collect::<Vec<_>>().join("\n");
                  HookResult::block_with_fix(
                      "validate-trajectory-tail-cell-completeness",
                      &format!(
                          "STATE.md trajectory_tail missing from {} prescribed site(s) (D-453(d)):\n{}",
                          missing.len(), sites
                      ),
                      "Add trajectory_tail arrow-sequence (→N→N→N→N, LENGTH=4 per D-433(e)) to each listed site",
                      "trajectory_tail_site_missing",
                  )
              }
          }
          TargetArm::Index => {
              for w in check_index_sites(&content) {
                  host::log_warn(&format!("validate-trajectory-tail-cell-completeness: {}", w.message));
              }
              HookResult::Continue
          }
          TargetArm::BurstLog => {
              for w in check_burst_log_sites(&content) {
                  host::log_warn(&format!("validate-trajectory-tail-cell-completeness: {}", w.message));
              }
              HookResult::Continue
          }
          TargetArm::Lessons => {
              for w in check_lessons_sites(&content) {
                  host::log_warn(&format!("validate-trajectory-tail-cell-completeness: {}", w.message));
              }
              HookResult::Continue
          }
      }
  }
  ```
