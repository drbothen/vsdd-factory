# S-23.08: Corpus migration — STORY-INDEX.md (597 live pins)

## Narrative

- **As a** state-manager/consistency-validator executing ADR-045's mechanical corpus migration
- **I want** to run the S-23.02 codemod against `.factory/stories/STORY-INDEX.md` — the single
  largest live-pin concentration in the entire corpus (597 of ~3,074) — and commit the result as
  one atomic commit
- **So that** the largest INDEX file is fully migrated, and future story-registration bursts
  (state-manager's per-story registration work) no longer hand-author inline version tokens in
  STORY-INDEX body table cells

## Context / Problem Statement

ADR-045 §Consequences, Negative/Trade-offs names STORY-INDEX.md's 597 live pins as the largest of
the 4-INDEX-files cluster. STORY-INDEX.md's own recent version history (v4.391, per this epic's
research read) shows extremely dense per-story amendment narrative with heavy inline version-token
usage in its own `last_amended:`/`modified:` chains — this story's codemod run must be especially
careful to preserve that historical narrative unchanged (S-23.01 AC-001/AC-007) while migrating
only the live body-table citation cells that reference BC/ADR/VP/Story IDs with a load-bearing
inline version.

## Acceptance Criteria

### AC-001
Running the codemod in `--dry-run` mode against STORY-INDEX.md produces a diff report reviewed
before apply. (traces to ADR-045 §Migration Plan Phase A step 5; S-23.02 AC-006)

### AC-002
The codemod does not modify any of STORY-INDEX.md's dense `last_amended:`/`modified:`/`[Prior:]`
historical narrative chains — these are, by volume, the majority of STORY-INDEX.md's total
version-token content and are exempt per S-23.01 AC-001. (traces to ADR-045 §Decision, Tier 1,
"Permitted exceptions"; S-23.01 AC-001)

### AC-003
The codemod migrates STORY-INDEX.md's live body-table cells (per-story Wave/Points/BCs summary
rows, Epic section descriptions) that cite BC/ADR/VP/Story IDs with an inline version token,
converting them to stable-anchor form. (traces to ADR-045 §Decision, Tier 1, "Permitted forms")

### AC-004
The migration is applied as exactly one atomic commit touching only STORY-INDEX.md. (traces to
ADR-045 §Migration Plan Phase A step 5; TD-VSDD-053)

### AC-005
Post-commit, S-23.03's guard and S-23.05's extended parity gate pass against STORY-INDEX.md with
zero findings. (traces to S-23.03 AC-001/AC-003; S-23.05 AC-001)

### AC-006 (negative control)
Post-commit, a targeted grep for live-section inline version pins in STORY-INDEX.md returns zero
matches, while a parallel grep restricted to `modified:`/`last_amended:`/`[Prior:]` sections
confirms that historical content is unchanged (byte-for-byte diff against the pre-migration
version of those specific sections). (traces to ADR-045 §Consequences Positive; S-23.01 AC-001)
