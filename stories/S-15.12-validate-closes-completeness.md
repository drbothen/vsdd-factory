# S-15.12: validate-closes-completeness WASM Hook Phase 1

**Epic:** E-12 — Engine Governance (brownfield-backfill wave, S-15.03 PRIORITY-A M3)
**Delivery order:** M3 (can ship independently; blocks S-15.13)
**Depends on:** none (independent new crate; zero blocking dependencies)
**Blocks:** S-15.13 (Phase 2 extends this crate; must ship first)
**Priority:** P1 (closes D-419(c)+D-420(e)+D-441(c)+D-442(c)+D-443(b)+D-448(b))

## Narrative

- **As a** state-manager or agent writing to `decision-log.md`, `STATE.md`, `INDEX.md`, or
  `lessons.md` in a fix burst
- **I want to** receive an immediate PostToolUse block when a Closes block entry uses a
  forbidden per-mechanism annotation, when an umbrella citation range is missing the
  sample-vs-exhaustive flag, or when a lessons.md entry is missing its mandatory `**Closes:**`
  bold-prefix line
- **So that** the class of Closes annotation structural violations — which the adversary
  discovered repeatedly across passes 39–74+ — is caught mechanically at write time rather
  than discovered N bursts later

## Why This Exists

The F5 engine-discipline cycle generated persistent adversary findings around Closes annotation
format and completeness. D-419(c) codified the prohibition on `(per D-413(b) completeness mandate)`
aggregate annotations. D-420(e) prohibited per-finding mechanism annotations in Closes blocks.
D-441(c)+D-442(c) required sample-vs-exhaustive flags on all umbrella citation ranges. D-443(b)
required explicit documentary-historical exemption declarations. D-448(b) required lessons.md
entries to have `**Closes:**` bold-prefix lines (not `### Closes` h3 headings).

Manual adherence never held — every cycle produced at least one Closes annotation finding.
This hook makes the entire Closes structural-format failure class impossible at PostToolUse time.

## Goal

Deliver a production-grade WASM hook (`validate-closes-completeness`) that PostToolUse-blocks
any Edit/Write to `decision-log.md`, `STATE.md`, `INDEX.md`, or `lessons.md` containing:
- A `**Closes:**` line with forbidden per-mechanism annotation patterns (D-419(c)+D-420(e))
- A bare umbrella citation `D-\d+\.\.D-\d+` without an adjacent sample-vs-exhaustive flag (D-441(c))
- A `lessons.md` entry lacking a `**Closes:**` bold-prefix line (D-448(b))
- A pre-D-448(b) exemption silently omitted without explicit declaration (D-443(b))

## D-NNN Sub-Clauses Closed (Phase 1)

| Sub-clause | What It Requires the Hook to Enforce |
|------------|---------------------------------------|
| D-419(c) | Closes cite ID format — structured IDs required; freeform prose or aggregate annotations forbidden. Enforcement: scan `**Closes:**` lines for unrecognized non-ID patterns. Cite IDs matching `D-\d+`, `F-P\d+-\d+`, `TD-VSDD-\d+`, `PG-[A-Za-z0-9-]+`, `L-EDP1-\d+`, `ADV-EDP1-P\d+-[A-Z]+-\d+` are valid; any other freeform content that is not a blank line or markdown formatting triggers block. |
| D-420(e) | Per-finding mechanism annotations in Closes blocks forbidden. Enforcement: detect pattern `\(per D-413\(b\) (completeness )?mandate\)` and the phrase `N items per D-413(b)` in `**Closes:**` lines; emit block. |
| D-441(c) | Sample-vs-exhaustive flag required on umbrella citation sites in STATE.md, INDEX.md, decision-log.md. Enforcement: detect bare `D-\d+\.\.D-\d+` patterns without adjacent `(sample)`, `(exhaustive)`, `sample-vs-exhaustive`, or `see decision-log.md for full range` flags; emit block. |
| D-442(c) | Retroactive sweep for sample-vs-exhaustive flag. Enforcement: same check as D-441(c) — applies on every write to the four target files. |
| D-443(b) | Documentary-historical exemption must be explicit (not silent). Enforcement: lessons.md entries lacking `**Closes:**` AND lacking `(documentary-historical)` or `(pre-D-448(b) exemption)` inline note → block. Silent omission is NOT valid per BC-5.39.007 invariant 7. |
| D-448(b) | lessons.md entries MUST have `**Closes:**` bold-prefix line. Enforcement: each h2 entry (`## L-` or `## PG-`) must contain at least one `**Closes:**` line with non-empty content; `### Closes` h3 heading is NOT canonical and triggers block. |

- [ ] T-5: Implement `src/lib.rs` with the following function structure:

  ```
  pub fn is_lessons_md_target(file_path: &str) -> bool
  pub fn is_state_md_target(file_path: &str) -> bool
  pub fn is_index_md_target(file_path: &str) -> bool
  pub fn is_decision_log_target(file_path: &str) -> bool
  ```
  Each uses `Path::new(file_path).file_name().and_then(|n| n.to_str()) == Some("<name>")`.
  MUST NOT use `ends_with`. The four target file names are: `lessons.md`, `STATE.md`,
  `INDEX.md`, `decision-log.md`.

  ```
  fn find_lesson_entries(content: &str) -> Vec<LessonEntry>
  ```
  Scan `lessons.md` content for h2 headings matching `^## (L-|PG-)`. Each heading starts a
  new lesson entry. Return Vec<LessonEntry> with (heading_text, entry_body) pairs. Entry body
  runs from h2 line to the next h2 or end-of-content.

  ```
  fn check_closes_present(entry: &LessonEntry) -> Option<Violation>
  ```
  For a lesson entry: check that the entry body contains a `**Closes:**` bold-prefix line with
  non-empty content after the colon. Returns Some(Violation) if:
  - No `**Closes:**` line present (and no exemption declaration)
  - `**Closes:**` present but content is empty or whitespace-only
  - `### Closes` h3 heading used instead of `**Closes:**` bold-prefix
  Exempt if body contains `(documentary-historical)` or `(pre-D-448(b) exemption)`.

  ```
  fn check_forbidden_annotations(line: &str) -> Option<Violation>
  ```
  Match patterns in `**Closes:**` lines:
  - `\(per D-413\(b\) (?:completeness )?mandate\)` → forbidden aggregate annotation
  - `\d+ items per D-413\(b\)` → forbidden shorthand aggregate
  Return Some(Violation) if matched, citing D-420(e).

  ```
  fn check_cite_id_format(closes_line: &str) -> Option<Violation>
  ```
  Extract content after `**Closes:**`. Check each comma-separated token against structured ID
  patterns: `D-\d+`, `F-P\d+-\d+`, `TD-VSDD-\d+`, `PG-[A-Za-z0-9-]+`, `L-EDP1-\d+`,
  `ADV-EDP1-P\d+-[A-Z]+-\d+`. Freeform tokens (no pattern match, not blank, not `---`)
  → Some(Violation) citing D-419(c). IMPORTANT: cross-site staleness (correctly formatted ID
  that doesn't exist in decision-log) is Phase 2 only — log_warn advisory, NOT block.

  ```
  fn check_umbrella_flag(content: &str) -> Vec<Violation>
  ```
  Scan content for bare umbrella citation patterns `D-\d+\.\.D-\d+`. For each found: check
  that the same sentence/paragraph also contains one of: `(sample)`, `(exhaustive)`,
  `sample-vs-exhaustive`, `see decision-log.md for full range`. If not: add Violation citing
  D-441(c)+D-442(c). This function applies to STATE.md, INDEX.md, and decision-log.md arms.

  ```
  fn run_hook(payload: &Payload) -> HookResult
  ```
  1. Determine target arm via `is_*_target` guards.
  2. Read file via `host::read_file(file_path, 524288, 2000)`. On HostError: return
     `HookResult::Continue` + `host::log_warn` (fail-open per BC-5.39.007 invariant 9).
  3. Accumulate violations based on arm:
     - lessons.md: run `find_lesson_entries` → per-entry `check_closes_present` + `check_forbidden_annotations` on Closes lines + `check_cite_id_format` on Closes lines + `check_umbrella_flag`
     - STATE.md: run `check_umbrella_flag` on body (NOT lesson-entry checks)
     - INDEX.md: run `check_umbrella_flag`
     - decision-log.md: run `check_umbrella_flag`
  4. If no violations: `HookResult::Continue`.
  5. If violations: single `HookResult::block_with_fix(hook, reason, recommendation, code)`
     enumerating all violations (BC-5.39.007 postcondition 9).

  **Structural requirements:**
  - `cited_raw: String` field in Violation struct — populate at every site
  - No `unwrap()` or `expect()` in production paths
  - `host::log_info/warn/error`, not `println!`
  - `is_char_boundary()` guards on all byte-index slice operations (lessons.md contains
    multi-byte narrative text; em-dash and typographic apostrophes are common per BC-5.39.007
    invariant 10)
  - Advisory-only path for cross-site staleness: when cite ID format is valid but references
    a nonexistent D-NNN, emit `host::log_warn` and do NOT add to violations Vec (Phase 2 only)
