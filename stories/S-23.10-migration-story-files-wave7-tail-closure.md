# S-23.10: Corpus migration — story files document class (73 files) — CLOSES the Wave-7 residual version-pin tail

## Narrative

- **As a** state-manager/consistency-validator executing ADR-045's mechanical corpus migration
- **I want** to run the S-23.02 codemod across all 73 story files identified in ADR-045's corpus
  scan, converting every live inline `BC-S.SS.NNN vN.NN` / `ADR-NNN §Decision N vX.Y` /
  `S-EE.NN vX.Y` / `VP-NNN vX.Y` citation to stable-anchor form
- **So that** the Wave-7 pre-TDD convergence floor — five of six wave-7 stories held at 0/3 CLEAN
  by a self-regenerating version-pin-propagation failure class across passes 4-9 (D-1075 through
  D-1080) — is closed structurally: a future BC/ADR/VP/Story version bump no longer forces any
  downstream story-body edit

## Context / Problem Statement

This is the story ADR-045 §Migration Plan Phase A step 6 refers to directly: "Wave-7's residual
tail closes as part of step 5 — all stories re-anchored to stable forms in the corpus migration
burst; adversary passes clear cleanly on the version-pin axis." ADR-045 §Context documents the
exact mechanism: "a remediation burst updates `BC-1.03.017` from vN to vN+1, which requires all
citing documents — every story body, every BC-table Version cell, every traceability row — to be
re-anchored in the same commit... the next adversary pass finds them, a new remediation burst
updates the BC to vN+2..., and the cycle repeats." At ADR-045's authoring, five of the six wave-7
stories (S-21.19, S-21.20, S-21.21, S-21.23; S-21.22 achieved 3/3 CLEAN at pass 5 but was reset)
remained at 0/3 CLEAN purely on this axis, despite the implementation axis being fully correct.

This story's scope is the full 73-file story document class per ADR-045's corpus scan, not merely
the four wave-7 stragglers — but the wave-7 stragglers are the story's primary acceptance
evidence, since they are the documented, named instance of the failure class this migration
eliminates.

## Acceptance Criteria

### AC-001
Running the codemod in `--dry-run` mode across all 73 story files (per ADR-045's corpus scan
file list, reconstructed at execution time via `.factory/stories/*.md` glob excluding
`STORY-INDEX.md` and `legacy-id-mapping.md`) produces a diff report reviewed before apply.
(traces to ADR-045 §Migration Plan Phase A step 5; S-23.02 AC-006/AC-007)

### AC-002
Specifically, S-21.19.md, S-21.20.md, S-21.21.md, and S-21.23.md each have every live inline
`BC-1.03.017 vX.Y`-shaped and `ADR-044`-anchor-interposed citation converted to stable-anchor
form (`BC-1.03.017`, `ADR-044 §<anchor>`). (traces to ADR-045 §Context, "every straggler finding
from pass 4 onward is a version-pin propagation failure"; ADR-045 §Migration Plan Phase A step 6,
"Wave-7's residual tail closes")

### AC-003
The codemod does not modify any story file's `modified:`/`last_amended:`/`[Prior:]` frontmatter
changelog chains, nor any `## Changelog`/`## Amendment` section — including the extremely dense
per-pass amendment history observed in files like S-21.25.md (6 `modified:` entries documenting
5 adversarial-pass fix bursts). (traces to S-23.01 AC-001; ADR-045 §Decision, Tier 1, "Permitted
exceptions")

### AC-004
The migration is applied as exactly one atomic commit touching the 73 story files (or, if the
implementer determines the diff is too large for a single reviewable commit, a small,
consistently-partitioned set of commits — e.g., by epic prefix — each still satisfying
TD-VSDD-053's "one atomic commit per document class" at the sub-partition granularity, with the
partitioning scheme recorded in this story's commit body). (traces to ADR-045 §Migration Plan
Phase A step 5, "one atomic commit per document class to respect TD-VSDD-053")

### AC-005
Post-commit, S-23.03's guard and S-23.05's extended parity gate pass against all 73 migrated
story files with zero findings. (traces to S-23.03 AC-001/AC-003; S-23.05 AC-001)

### AC-006
Post-migration, a fresh adversarial pass dispatched against S-21.19, S-21.20, S-21.21, and
S-21.23 (per the existing per-story adversarial convergence workflow, E-12) finds zero
version-pin-propagation-class findings — the specific defect pattern documented across D-1075
through D-1080 does not recur. (traces to ADR-045 §Consequences Positive, "3-CLEAN convergence
loop stabilized... The floor that held Wave-7 convergence at 0/3 across passes 4-9 is structurally
removed")

### AC-007 (negative control)
Post-commit, a targeted newline-normalized grep for
`\b(ADR-\d+|BC-\d+(?:\.\d+)+|S-\d+\.\d+|VP-\d+)\b[^\n]{0,80}\bv\d+(?:\.\d+)*\b` restricted to
live (non-exempt) sections across all 73 story files returns zero matches. (traces to ADR-045
§Consequences Positive, "Cohort re-anchoring eliminated by construction")

### AC-008
This story's commit body explicitly states "CLOSES Wave-7 residual version-pin tail (S-21.19,
S-21.20, S-21.21, S-21.23)" and cites ADR-045 §Migration Plan Phase A step 6, so the closure is
discoverable in the commit history independent of this story file. (traces to CLAUDE.md
Architectural Authority — decision-log/burst-log discoverability discipline)
