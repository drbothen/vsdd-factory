# S-7.09 — Fix-Burst Mandatory Exit Sweep — codify per-hit sibling-sweep gate into fix-burst protocol

**Epic:** E-7 — Process Codification (Self-Improvement)
**Source:** D-869 cascade totals (passes 6–8 consumed by sibling-sweep residue), D-869 item (6)(c)
**Depends on:** S-7.08 (adds PERSIST gate to SKILL.md; this story adds the EXIT SWEEP gate to the same SKILL.md — sequential amendments to prevent merge conflicts)
**Priority:** P1 (prevents pass-count inflation from sibling-sweep escapes, which distort the convergence streak)
**Subsystem anchor:** SS-05 (Pipeline Orchestration) + SS-06 (Skill Catalog)

## Narrative

- **As a** vsdd-factory fix-burst agent (architect or state-manager) completing a fix burst
- **I want** a mandatory exit-sweep step at the end of every fix burst: grep all corrected phrase classes across the relevant artifact tree, attach per-hit verdicts verbatim, and block "done" declaration until all in-scope hits are triaged
- **So that** sibling-site residue of the corrected phrases does not survive to the next adversary pass, consuming that pass on a finding the fix burst could have caught itself

During the ADR-032 cascade, fix bursts 4, 5, and 6 each corrected a phrase class (e.g.,
relabeling fabricated-provenance identifiers, correcting priority-slot references, adjusting
code-inline annotations). In each case, the fix was applied to the primary occurrence but
sibling occurrences in changelog entries, cross-references, or prose sections were missed.
The next adversary pass re-found the residue, consuming a pass. This repeated across three
consecutive passes before fix burst 6 imposed a post-fix grep sweep ad hoc.

TD-VSDD-060 (sibling-site sweep on value changes) already requires this for Rust code changes.
This story extends the same discipline to skill-doc fix bursts, where the corrected content is
Markdown prose rather than Rust identifiers, and adds the per-hit-verdict requirement that
TD-VSDD-060 does not prescribe.

The exit sweep is codified in three places:
1. `adversarial-review SKILL.md` — the canonical fix-burst protocol reference
2. `architect.md` — the primary fix-burst agent for spec/ADR changes
3. `state-manager.md` — the primary fix-burst agent for factory-artifact changes

## Edge Cases

| ID | Scenario | Expected Behavior |
|----|----------|-------------------|
| EC-001 | The corrected phrase appears only once in the entire artifact tree and the fix was applied to that occurrence | EXIT SWEEP confirms single hit with verdict (a) already-fixed; sweep stdout still attached verbatim; "done" may be declared |
| EC-002 | A corrected phrase appears in a CHANGELOG or `last_amended` line as historical record (not a normative occurrence) | Per-hit verdict (c) justified-exception with reason "historical changelog record; normative content already corrected"; sweep stdout still attached |
| EC-003 | The phrase class is a format string with variants (e.g., `F-ADR032-P5-` and `F-ADR032-P5R-` are distinct families) | Each distinct variant is a separate sweep grep; EXIT SWEEP must cover ALL variants corrected in the burst |
| EC-004 | The fix burst corrects five independent phrase classes | Five separate grep commands, each with stdout attached; the exit-sweep section has one block per phrase class |
