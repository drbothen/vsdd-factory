# VP-102: Fuel-Exhaustion and Epoch-Timeout Yield INDETERMINATE Outcome for fail-closed Plugin

## Property Statement

For any plugin with `failure_policy = FailClosed`:

When the executor observes `PluginResult::Timeout { cause: TimeoutCause::Fuel }` or
`PluginResult::Timeout { cause: TimeoutCause::Epoch }`, the resulting outcome classification
MUST be `DispatchOutcome::Indeterminate` — never `DispatchOutcome::Pass`.

Negative constraint: For a plugin with `failure_policy = FailOpen`, the same
`PluginResult::Timeout{Fuel}` or `Timeout{Epoch}` MUST NOT produce a blocking INDETERMINATE
classification (it produces an advisory-only event).

Normal PASS (`PluginResult::Ok { exit_code: 0 }`) and normal FAIL (`PluginResult::Ok { exit_code: non-zero }`)
semantics are UNCHANGED by this property — INDETERMINATE is a third classification class, not a
replacement for PASS or FAIL.

## Source Contract

- **BC:** BC-1.18.001 §Postcondition 1 — fail-closed
  plugin that cannot complete due to resource exhaustion MUST yield INDETERMINATE outcome, not PASS.
- **ADR:** ADR-047 §Decision 1 — Outcome Trichotomy (PASS / FAIL / INDETERMINATE); INDETERMINATE
  triggered by `PluginResult::Timeout{Fuel}` and `PluginResult::Timeout{Epoch}` for fail-closed plugins.
- **ADR:** ADR-047 §Decision 7 — Backward-compatibility contract; PASS/FAIL semantics unchanged.
- **ADR:** ADR-039 §Decision 1 — `failure_policy` field semantics; `FailClosed` means
  cannot-complete is fail-LOUD, not fail-silent.

## Proof Method

| Method | Tool | Bounded? | Coverage |
|--------|------|----------|----------|
| unit-test | Rust (#[test]) | yes — 5 cases covering complete decision table | Fuel→INDETERMINATE; Epoch→INDETERMINATE; fail-open fuel→NOT-INDETERMINATE; normal pass preserved; normal fail preserved |

### Why unit-test

`classify_outcome` is a pure function of `(PluginResult, FailurePolicy, bool) → DispatchOutcome`.
No I/O dependencies, no WASM runtime, no filesystem. Unit-test coverage is complete and sufficient.
Integration testing is covered by VP-105 (marker+gate end-to-end) which exercises the full
INDETERMINATE path through the real dispatcher binary.

## Proof Harness Skeleton

```rust
// crates/factory-dispatcher/src/tests/vp_102_indeterminate_timeout.rs
// VP-102: BC-1.18.001 PC1 — fuel/epoch timeout → INDETERMINATE for fail-closed plugins

#[cfg(test)]
mod vp_102 {
    use super::*;
    use crate::executor::{classify_outcome, DispatchOutcome, FailurePolicy, PluginResult, TimeoutCause};

    #[test]
    fn test_BC_1_18_001_fuel_exhaustion_fail_closed_yields_indeterminate() {
        let result = PluginResult::Timeout { cause: TimeoutCause::Fuel };
        let policy = FailurePolicy::FailClosed;
        let host_output_too_large_seen = false;
        let outcome = classify_outcome(&result, policy, host_output_too_large_seen);
        assert_eq!(outcome, DispatchOutcome::Indeterminate,
            "VP-102: Fuel exhaustion on fail-closed plugin MUST yield INDETERMINATE (BC-1.18.001 PC1)");
    }

    #[test]
    fn test_BC_1_18_001_epoch_timeout_fail_closed_yields_indeterminate() {
        let result = PluginResult::Timeout { cause: TimeoutCause::Epoch };
        let policy = FailurePolicy::FailClosed;
        let host_output_too_large_seen = false;
        let outcome = classify_outcome(&result, policy, host_output_too_large_seen);
        assert_eq!(outcome, DispatchOutcome::Indeterminate,
            "VP-102: Epoch timeout on fail-closed plugin MUST yield INDETERMINATE (BC-1.18.001 PC1)");
    }

    #[test]
    fn test_BC_1_18_001_fuel_exhaustion_fail_open_does_not_yield_blocking_indeterminate() {
        // Negative case: fail-open timeout must NOT produce blocking INDETERMINATE
        let result = PluginResult::Timeout { cause: TimeoutCause::Fuel };
        let policy = FailurePolicy::FailOpen;
        let host_output_too_large_seen = false;
        let outcome = classify_outcome(&result, policy, host_output_too_large_seen);
        assert_ne!(outcome, DispatchOutcome::Indeterminate,
            "VP-102: Fuel exhaustion on fail-open plugin MUST NOT yield blocking INDETERMINATE (ADR-047 §D7)");
    }

    #[test]
    fn test_BC_1_18_001_normal_pass_unaffected_by_indeterminate_path() {
        let result = PluginResult::Ok { exit_code: 0 };
        let policy = FailurePolicy::FailClosed;
        let host_output_too_large_seen = false;
        let outcome = classify_outcome(&result, policy, host_output_too_large_seen);
        assert_eq!(outcome, DispatchOutcome::Pass,
            "VP-102: Normal Ok{exit_code:0} MUST remain PASS; INDETERMINATE must not contaminate PASS path");
    }

    #[test]
    fn test_BC_1_18_001_normal_fail_unaffected_by_indeterminate_path() {
        let result = PluginResult::Ok { exit_code: 1 };
        let policy = FailurePolicy::FailClosed;
        let host_output_too_large_seen = false;
        let outcome = classify_outcome(&result, policy, host_output_too_large_seen);
        assert_eq!(outcome, DispatchOutcome::Fail,
            "VP-102: Normal Ok{exit_code:1} MUST remain FAIL; existing AMD-003 semantics preserved");
    }
}
```
