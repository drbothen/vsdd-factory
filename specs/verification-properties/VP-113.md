# VP-113: D-1144 Escape Remediation Produces Strictly-Valid YAML

## Property Statement

1. `needs_escaping` correctly detects an unescaped literal `"` and correctly does NOT flag
   already-escaped quotes or a trailing escaped backslash before a quote.
2. `escape_value` escapes every unescaped literal `"` to `\"` while preserving all other
   characters (including already-escaped backslashes) verbatim.
3. `escape_value` is idempotent — escaping an already-escaped value produces no further change.
4. `migrate_file`'s D-1144 remediation path rewrites a defective `BC-INDEX.md`-shaped
   `last_amended` entry (containing an unescaped `"`) so the result parses cleanly under strict
   YAML `safe_load`, with the entry's substantive text otherwise unchanged.
5. `migrate_file` never flags `escape_fixed` on an already-clean entry (no false positives).
6. Re-running the escape fix across multiple invocations is idempotent — no double-escaping.

## Source Contract

- **BC:** BC-10.13.001 §Postcondition 3 (PC3) — D-1144 escape remediation on the three defective
  files (and on any relocated PC7 split entry); Invariant 4 — every write the tool performs
  parses under strict YAML `safe_load`.
- **ADR:** ADR-049 §Decision 6, §Decision 7.

## Proof Method

| Method | Tool | Bounded? | Coverage |
|--------|------|----------|----------|
| unit-test | Rust (`#[test]`) | yes — fixed input/output pairs | `needs_escaping`/`escape_value` unit coverage (positive, negative, already-escaped-backslash, idempotency); `migrate_file` end-to-end BC-INDEX.md-shaped quote-defect fixture; idempotent-re-escape-across-runs fixture; clean-entry-never-flagged negative control |

### Why unit-test

Escape correctness is a pure string-transformation property (`needs_escaping`/`escape_value`) plus
one end-to-end integration-style fixture confirming the transformed value round-trips through
strict YAML `safe_load`. The BC's original candidate proof method (`integration: strict YAML
safe_load round-trip on all 3 remediated fixtures`) is satisfied by the `migrate_file`-level test
cases in the harness below, which exercise the real `BC-INDEX.md`-shaped fixture end-to-end through
the same YAML-parse round-trip.
