# VP-096: extract_frontmatter Purity — Output Byte-Equals File Prefix Up To (Excluding) the Second --- Delimiter Line (bytes 0..delimiter_start_offset; opening ---\n included); Deterministic for Any Input

## Property Statement

`factory_lock_parse::extract_frontmatter(input: &[u8]) -> &[u8]` MUST be a pure deterministic
function satisfying four invariants:

1. **Byte-exact prefix (LF and CRLF):** for any input that contains a closing delimiter in
   either LF form (`\n---\n`) or CRLF form (`\r\n---\r\n`), the returned slice equals the
   bytes of the input from byte 0 up to (but excluding) the leading byte of that closing
   delimiter — `&input[..delimiter_start_offset]`, where `delimiter_start_offset` is the byte
   index of the `\n` beginning `\n---\n` (LF) or the `\r` beginning `\r\n---\r\n` (CRLF),
   per BC-4.13.001 Invariant 9 (v1.15). The opening delimiter (`---\n` for LF; `---\r\n` for
   CRLF) is included in the output; the closing delimiter sequence and all bytes after it are
   excluded.
2. **No content at or beyond closing delimiter:** the closing delimiter sequence itself and all
   bytes after it are excluded from the output.
3. **Determinism:** calling `extract_frontmatter` twice on the same input MUST return
   byte-identical slices.
4. **No-fence fallback:** if neither `\n---\n` (LF form) nor `\r\n---\r\n` (CRLF form) is
   present in the input, returns the entire input unchanged (fail-open: callers see the full
   content and may fail to parse, but no panic occurs).

These four properties close the assertion that `parse_factory_lock` and
`extract_yaml_string_value` never read past the frontmatter block, eliminating body-size scaling
(ADR-025 Decision 14; BC-4.13.001 §Invariant 9).

## Source Contract

- **BC:** BC-4.13.001 §Invariant 9 (v1.15) — `extract_frontmatter` output = bytes
  0..`delimiter_start_offset`; closing delimiter recognized in both LF form (`\n---\n`) and
  CRLF form (`\r\n---\r\n`); `delimiter_start_offset` = byte index of the leading `\n` (LF)
  or `\r` (CRLF) of the closing delimiter; opening delimiter included; no body content read;
  byte-exact-prefix invariant holds for both forms (EC-017).
- **ADR:** ADR-025 Decision 14 — frontmatter-only parse mandate; body-size scaling elimination
  rationale.

## Proof Method

| Method | Tool | Bounded? | Coverage |
|--------|------|----------|----------|
| proptest | Rust proptest crate | yes — 1024 trials per run, arbitrary byte input | byte-exact prefix; no-fence fallback; determinism; boundary: delimiter at position 0, 1, last byte |

### Why proptest

`extract_frontmatter` is a pure function over `&[u8]` input. All four properties are checkable
as pure postconditions over arbitrary byte inputs, making proptest the natural choice. No
filesystem I/O; no WASM runtime. Kani is a viable upgrade candidate once the function is stable.

## Proof Harness Skeleton

```rust
// File: crates/factory-lock-parse/tests/proptest_extract_frontmatter.rs
use factory_lock_parse::extract_frontmatter;
use proptest::prelude::*;

/// Find delimiter_start_offset per BC-4.13.001 Invariant 9 (v1.15):
/// the byte index of the leading byte of the closing delimiter sequence —
/// the `\n` beginning `\n---\n` (LF form) or the `\r` beginning `\r\n---\r\n`
/// (CRLF form). The extract_frontmatter output is input[0..delimiter_start_offset].
/// LF form is tried first; CRLF form is the fallback.
fn find_second_fence_start(input: &[u8]) -> Option<usize> {
    // LF form: \n---\n (5 bytes). The returned index is the position of the
    // leading \n, which is delimiter_start_offset for LF inputs.
    let lf_delim = b"\n---\n";
    if let Some(pos) = input.windows(lf_delim.len()).position(|w| w == lf_delim) {
        return Some(pos);
    }
    // CRLF form: \r\n---\r\n (7 bytes). The returned index is the position of
    // the leading \r, which is delimiter_start_offset for CRLF inputs.
    let crlf_delim = b"\r\n---\r\n";
    input.windows(crlf_delim.len()).position(|w| w == crlf_delim)
}

proptest! {
    #![proptest_config(ProptestConfig::with_cases(1024))]

    #[test]
    fn prop_byte_exact_prefix(input in proptest::collection::vec(any::<u8>(), 0..4096)) {
        let result = extract_frontmatter(&input);
        match find_second_fence_start(&input) {
            Some(start) => {
                // Invariant 1: output equals prefix up to (excluding) second fence
                prop_assert_eq!(result, &input[..start],
                    "extract_frontmatter output must equal input[..delimiter_start_offset]");
                // Invariant 2: no byte at or past fence
                prop_assert!(result.len() == start);
            }
            None => {
                // Invariant 4: no-fence fallback returns entire input
                prop_assert_eq!(result, input.as_slice(),
                    "extract_frontmatter must return full input when fewer than 2 fences");
            }
        }
    }

    #[test]
    fn prop_deterministic(input in proptest::collection::vec(any::<u8>(), 0..4096)) {
        // Invariant 3: determinism
        let r1 = extract_frontmatter(&input);
        let r2 = extract_frontmatter(&input);
        prop_assert_eq!(r1, r2, "extract_frontmatter must be deterministic");
    }

    #[test]
    fn prop_no_panic_on_arbitrary_bytes(input in proptest::collection::vec(any::<u8>(), 0..65536)) {
        // Safety: no panic on any input up to 64 KiB
        let _ = extract_frontmatter(&input);
    }

    #[test]
    fn prop_byte_exact_prefix_crlf(
        // Exclude \r and \n from content so no embedded fence pattern can appear
        // and the explicit \r\n---\r\n appended below is guaranteed to be the
        // first (and only) closing delimiter in the constructed input.
        content in proptest::collection::vec(
            any::<u8>().prop_filter("no CR/LF", |b| *b != b'\r' && *b != b'\n'),
            0..256
        ),
        body in proptest::collection::vec(any::<u8>(), 0..256),
    ) {
        // Construct: ---\r\n<content>\r\n---\r\n<body>
        // delimiter_start_offset = 5 + content.len() (the \r beginning \r\n---\r\n).
        let mut input = b"---\r\n".to_vec();
        input.extend_from_slice(&content);
        let expected_offset = input.len(); // index of the \r that begins \r\n---\r\n
        input.extend_from_slice(b"\r\n---\r\n");
        input.extend_from_slice(&body);

        // Oracle must locate the CRLF delimiter at expected_offset.
        prop_assert_eq!(
            find_second_fence_start(&input),
            Some(expected_offset),
            "CRLF oracle: find_second_fence_start must return index of leading \\r of \\r\\n---\\r\\n"
        );
        let result = extract_frontmatter(&input);
        // Invariant 1 (CRLF form): output = input[0..delimiter_start_offset]
        prop_assert_eq!(result, &input[..expected_offset],
            "CRLF: extract_frontmatter output must equal input[..delimiter_start_offset]");
        prop_assert!(result.len() == expected_offset);
    }
}
```
