# VP-095: verify-factory-lock Reads STATE.md Without output_too_large Denial for Sizes up to 262144 Bytes

## Property Statement

`verify-factory-lock` WASM plugin (via `host::read_file` with `max_bytes = STATE_MD_MAX_BYTES`)
MUST successfully read any STATE.md whose byte-size is in the range [65536, 262144] without
returning `OUTPUT_TOO_LARGE` (host code -3). For any file size in that range the host call MUST
return `Ok(content)` and the plugin MUST proceed to frontmatter parsing. The property closes the
rc.22 smoke FINDING-1 regression class (ADR-025 §Decision 14; BC-4.13.001 §Precondition 3).

Additionally, the boundary below the range (65535 bytes) also MUST NOT trigger `OUTPUT_TOO_LARGE`
since it is below the cap. Only files exceeding 262144 bytes may produce a cap-exceeded response.

## Source Contract

- **BC:** BC-4.13.001 §Precondition 3 — `STATE_MD_MAX_BYTES` constant is 262144; the
  `read_file` call in `verify-factory-lock` MUST use this cap.
- **ADR:** ADR-025 Decision 14 — `STATE_MD_MAX_BYTES` 65536→262144 rationale (256 KiB headroom);
  frontmatter-only parse mandate (body-size scaling elimination).

## Proof Method

| Method | Tool | Bounded? | Coverage |
|--------|------|----------|----------|
| integration | bats (dispatcher binary + synthetic STATE.md fixtures) | yes — 5 size boundary fixtures: 65535, 65536, 131072, 262144, 262145 | OUTPUT_TOO_LARGE absence for in-range sizes [65535..262144]; fail-open Continue + StateReadError warn for 262145 (BC-4.13.001 §PC6; soft-warn path not reached per §Invariant 10) |

### Why integration

The property spans the dispatcher's `host::read_file` implementation and the `STATE_MD_MAX_BYTES`
constant in `verify-factory-lock/src/lib.rs`. A pure unit test cannot exercise the full WASM host
ABI round-trip. Bats fixtures supply synthetic STATE.md files of calibrated sizes and assert the
plugin returns Continue (no block) without OUTPUT_TOO_LARGE.

## Proof Harness Skeleton

```bash
#!/usr/bin/env bats
# vp095-verify-factory-lock-size-cap.bats
# VP-095: BC-4.13.001 PC3 — no OUTPUT_TOO_LARGE for STATE.md up to 262144 bytes

PLUGIN_ROOT=""
SINK_FILE=""

setup() {
    PLUGIN_ROOT=$(mktemp -d)
    SINK_FILE=$(mktemp --suffix=.jsonl)
    mkdir -p "$PLUGIN_ROOT/hook-plugins"
}

teardown() {
    rm -rf "$PLUGIN_ROOT"
    rm -f "$SINK_FILE"
}

make_state_md() {
    local size="$1"
    local tmpfile
    tmpfile=$(mktemp)
    printf -- '---\nfactory_lock:\n  holder: ""\n  locked_at: ""\n  expires_at: ""\ntimestamp: "2026-07-06T00:00:00Z"\n---\n' > "$tmpfile"
    local current_size
    current_size=$(wc -c < "$tmpfile")
    local pad=$(( size - current_size ))
    if [ "$pad" -gt 0 ]; then
        printf '%0.s#' $(seq 1 "$pad") >> "$tmpfile"
    fi
    echo "$tmpfile"
}

run_guard() {
    local state_md="$1"
    mkdir -p "$PLUGIN_ROOT/.factory"
    cp "$state_md" "$PLUGIN_ROOT/.factory/STATE.md"
    local envelope
    envelope='{"hook_event_name":"PreToolUse","tool_name":"Edit","session_id":"vp095-test","tool_input":{"file_path":".factory/STATE.md","old_string":"x","new_string":"y"}}'
    printf '%s' "$envelope" | \
        CLAUDE_PLUGIN_ROOT="$PLUGIN_ROOT" \
        VSDD_SINK_FILE="$SINK_FILE" \
        CLAUDE_PROJECT_DIR="$PLUGIN_ROOT" \
        factory-dispatcher 2>/dev/null
}

@test "VP-095: 65535 bytes — no OUTPUT_TOO_LARGE (just under old cap)" {
    local f; f=$(make_state_md 65535)
    run run_guard "$f"
    rm -f "$f"
    if grep -q "OUTPUT_TOO_LARGE" "$SINK_FILE" 2>/dev/null; then
        echo "FAIL: OUTPUT_TOO_LARGE emitted for 65535-byte STATE.md"; return 1
    fi
}

@test "VP-095: 65536 bytes — no OUTPUT_TOO_LARGE" {
    local f; f=$(make_state_md 65536)
    run run_guard "$f"
    rm -f "$f"
    if grep -q "OUTPUT_TOO_LARGE" "$SINK_FILE" 2>/dev/null; then
        echo "FAIL: OUTPUT_TOO_LARGE emitted for 65536-byte STATE.md"; return 1
    fi
}

@test "VP-095: 131072 bytes — no OUTPUT_TOO_LARGE" {
    local f; f=$(make_state_md 131072)
    run run_guard "$f"
    rm -f "$f"
    if grep -q "OUTPUT_TOO_LARGE" "$SINK_FILE" 2>/dev/null; then
        echo "FAIL: OUTPUT_TOO_LARGE emitted for 131072-byte STATE.md"; return 1
    fi
}

@test "VP-095: 262144 bytes — no OUTPUT_TOO_LARGE (upper boundary)" {
    local f; f=$(make_state_md 262144)
    run run_guard "$f"
    rm -f "$f"
    if grep -q "OUTPUT_TOO_LARGE" "$SINK_FILE" 2>/dev/null; then
        echo "FAIL: OUTPUT_TOO_LARGE emitted for 262144-byte STATE.md (boundary violation)"; return 1
    fi
}

@test "VP-095: 262145 bytes — host returns OutputTooLarge; plugin fail-open Continue (no block); StateReadError warn emitted (BC-4.13.001 §PC6 + §Invariant 10)" {
    # BC-4.13.001 §Invariant 10 boundary table: 262145 → OutputTooLarge returned by host;
    # soft-warn path (state_md_approaching_cap) NOT reached (read failed before size measurement).
    # BC-4.13.001 §PC6: host returns OutputTooLarge HostError variant → plugin MUST return
    # HookResult::Continue after emitting host::log_warn with StateReadError(OutputTooLarge).
    local f; f=$(make_state_md 262145)
    run run_guard "$f"
    rm -f "$f"
    # Assert 1: plugin MUST NOT block — PC6 fail-open
    if grep -q '"block_intent":true' "$SINK_FILE" 2>/dev/null; then
        echo "FAIL: plugin blocked on 262145-byte STATE.md (PC6 fail-open violated)"; return 1
    fi
    # Assert 2: StateReadError warn MUST be present in sink — OutputTooLarge host error emitted
    if ! grep -qE "StateReadError|OutputTooLarge" "$SINK_FILE" 2>/dev/null; then
        echo "FAIL: StateReadError warn not found in sink for 262145-byte STATE.md (PC6 warn obligation)"; return 1
    fi
}
```
