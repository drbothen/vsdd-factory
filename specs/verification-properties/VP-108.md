# VP-108: marker.cleared Audited-Clear Event — Clear Path Emission Correctness (BC-1.18.003 §PC1/PC3/PC4; ADR-048 §D4 v1.3)

## Property Statement

For each of the four audited clear paths defined in BC-1.18.003 and ADR-048 §Decision 4
(REVALIDATED, TTL_EXPIRED, OPERATOR_OVERRIDE, and — as of v1.3 — SUPERSEDED), when a
`.factory/unvalidated-mutation.marker` is cleared or overwritten, the dispatcher MUST emit a
`marker.cleared` event via `HostContext::emit_internal` (never a raw `InternalLog::write`, never
the WASM `emit_event` host ABI) with the correct `clear_mode`, `actor_type`, `trace_id`,
`plugin_name`, `artifact_path`, `reason` (when applicable), and `timestamp` fields. The
crash-path native TTL-allow path (BC-1.18.003 §EC-014) MUST NOT emit a `marker.cleared`
event.

The five postconditions are:

**Postcondition 1 — REVALIDATED clear (BC-1.18.003 §PC1):**
When the same plugin+artifact_path pair that wrote the marker subsequently returns a PASS
outcome via `evaluate_gate`, the gate plugin deletes the marker (idempotent) and emits:
`marker.cleared` with `clear_mode = "REVALIDATED"`, `actor_type = "validator"`,
`trace_id = <current trace_id>`, `plugin_name = <plugin_name>`,
`artifact_path = <artifact_path>`, `reason = null` (absent), `timestamp = <ISO8601>`.

**Postcondition 2 — TTL_EXPIRED clear (BC-1.18.003 §PC4 — TTL-loudness) [v1.2 — emission-mechanism
corrected]:**
When the dispatcher-native `check_and_clear_expired_marker` pre-check (called from `executor.rs`'s
tier-execution loop, before invoking the Arm 1/Arm 2 WASM gate plugin) finds `expires_at <=
now(UTC)` (expired marker), it auto-deletes the marker and emits, via `ctx.emit_internal(ev)`:
`marker.cleared` with `clear_mode = "TTL_EXPIRED"`, `actor_type = "deadman"`, `trace_id = <marker's
own trace_id>`, `plugin_name = <marker's own plugin_name>`, `artifact_path = <marker's own
artifact_path>`, `reason = null` (absent), `timestamp = <ISO8601>`. This is the TTL-loudness
requirement per ADR-048 §Decision 4 — TTL auto-expiry is now an audited event, not a silent
self-healing path. **Correction (v1.1, ADR-048 §D4 v1.2):** this MUST NOT be emitted from inside
the WASM gate plugin's `evaluate_gate` — the `emit_event` host ABI's RESERVED_FIELDS enrichment
would unconditionally overwrite `trace_id`/`plugin_name` with the CURRENT gate-plugin's own
dispatch identity, not the marker's, making the wire contract above structurally unachievable from
WASM. By the time `evaluate_gate` runs (after this pre-check), the marker is guaranteed already
absent-or-non-expired, so `evaluate_gate` performs no TTL logic of its own. **Further correction
(v1.2, ADR-048 §D4 v1.3):** the emission call itself MUST be `ctx.emit_internal(ev)` (`ctx: &
HostContext`), NOT a raw `log.write(&ev)` call on a bare `&InternalLog` — `emit_internal` is the
same dual-sink primitive (InternalLog + `ctx.events` stub queue) every sibling BC-3.08.001
dispatcher-native event already uses; a raw `InternalLog::write` silently diverges from that
established pattern (S-25.01 pass-3 F-P3-001 MEDIUM) and never reaches `ctx.events` (the queue
`VSDD_SINK_FILE` and the future S-4.07 Router/FileSink both drain).

**Postcondition 3 — OPERATOR_OVERRIDE clear (BC-1.18.003 §PC3 + ADR-048 §D4) [v1.2 — emission-
mechanism + scan-target corrected]:**
When the dispatcher-native `reconcile_raw_delete` function (invoked from the same pre-check's
marker-absent branch) detects a `RAW_DELETE_DETECTED` condition (operator out-of-band marker
removal that occurred while the dispatcher was running, inferred via a bounded scan of the
current day's `dispatcher-internal-{date}.jsonl` — see scan-target correction below — for an
unmatched `plugin.indeterminate`), it retroactively emits, via `ctx.emit_internal(ev)`:
`marker.cleared` with `clear_mode = "OPERATOR_OVERRIDE"`, `actor_type =
"operator"`, `trace_id = <trace_id from the unmatched plugin.indeterminate event>`, `plugin_name
= <plugin_name>` (from the same unmatched event), `artifact_path = <artifact_path>` (from the
same unmatched event), `reason = <non-null string describing the operator action>`, `timestamp =
<ISO8601>`. The `reason` field MUST be non-null for OPERATOR_OVERRIDE. **Correction (v1.1,
ADR-048 §D4 v1.2):** this was PREVIOUSLY ENTIRELY UNIMPLEMENTED (S-25.01 pass-2 F-P2-003 MED);
this postcondition's function anchor (`reconcile_raw_delete`) is dispatcher-native for the same
RESERVED_FIELDS-wall reason as Postcondition 2 — it was never a candidate for WASM-plugin-side
implementation once the wall is understood. **Further correction (v1.2, ADR-048 §D4 v1.3) — scan
target:** the bounded scan MUST target `<InternalLog log_dir>/dispatcher-internal-{date}.jsonl`
(obtained via `ctx.internal_log.as_ref().map(|l| l.log_dir())`), NOT a literal `events-{date}
.jsonl`. `InternalLog` is the only log every default production dispatcher run writes
unconditionally; a literal `events-{date}.jsonl` file is not durably produced absent an opt-in
`VSDD_SINK_FILE` or the not-yet-`main.rs`-wired S-4.07 Router/FileSink. Scanning a file that is
not durably written would make RAW_DELETE_DETECTED permanently inert in every real deployment —
this is a load-bearing correction, not a cosmetic rename (S-25.01 pass-3 F-P3-001 MEDIUM).

**Postcondition 4 — Crash-path native TTL-allow does NOT emit (BC-1.18.003 §EC-014):**
When the dispatcher's native `block_if_marker_check` check finds an expired marker (PC6 path:
crash + absent/expired marker → Allow), the dispatcher allows the dispatch WITHOUT emitting
a `marker.cleared` event. Only `check_and_clear_expired_marker` (the normal-path pre-check;
Postcondition 2) emits `marker.cleared` on TTL_EXPIRED. The crash-path and the normal-path
pre-check are distinct dispatcher-native functions; `block_if_marker_check` runs only on plugin
crash/timeout and does not call `check_and_clear_expired_marker`, `reconcile_raw_delete`, or
`emit_marker_cleared`.

**Postcondition 5 — SUPERSEDED clear (BC-1.18.001 INV3 cross-pair overwrite; ADR-048 §D4 v1.3;
S-25.01 pass-3 F-P3-002 LOW) [NEW in v1.2]:**
When `write_indeterminate_marker`'s caller detects that a marker ALREADY EXISTS for a `(plugin_
name, artifact_path)` pair DIFFERENT from the new INDETERMINATE event about to overwrite it
(single-marker last-writer-wins, BC-1.18.001 INV3), it reads the EXISTING marker's fields BEFORE
the temp+rename overwrite and, via `ctx.emit_internal(ev)`, emits: `marker.cleared` with
`clear_mode = "SUPERSEDED"`, `actor_type = "system"`, `trace_id = <SUPERSEDED marker's own
trace_id>`, `plugin_name = <SUPERSEDED marker's own plugin_name>`, `artifact_path = <SUPERSEDED
marker's own artifact_path>`, `reason = "SUPERSEDED: marker overwritten by a new
plugin.indeterminate event for a different (plugin_name, artifact_path) pair before being
cleared; last-writer-wins (BC-1.18.001 INV3)"` (non-null — `SUPERSEDED` joins `OPERATOR_OVERRIDE`
as a `reason`-mandatory `clear_mode`), `timestamp = <ISO8601, time of the overwrite>`. When the
existing marker's `(plugin_name, artifact_path)` is the SAME as the new event's, NO `SUPERSEDED`
event is emitted (continuous quarantine of the same target, not a cross-pair supersession).
Rationale: without this event, `reconcile_raw_delete` (Postcondition 3) has no record that the
superseded pair was ever cleared, and a LATER raw-delete of the (now-different) marker causes it
to falsely emit `marker.cleared(OPERATOR_OVERRIDE)` for the superseded pair — attributing a human
action that never happened to that pair (a NIST AU-3/AU-10 event-content/non-repudiation defect).
`SUPERSEDED` closes the gap: `reconcile_raw_delete`'s existing `type == "marker.cleared" =>
unmatched.remove(&key)` match logic already treats any `clear_mode` as closing the key, so no
change to Postcondition 3's matching logic is required.

**Wire format (BC-3.08.001 Event 9 / ADR-048 §Decision 4 v1.3):**

| Field | Type | Required? | Notes |
|-------|------|-----------|-------|
| `type` | string | always | `"marker.cleared"` |
| `clear_mode` | string enum | always | `"REVALIDATED"` / `"TTL_EXPIRED"` / `"OPERATOR_OVERRIDE"` / `"SUPERSEDED"` (v1.3) |
| `actor_type` | string enum | always | `"validator"` / `"deadman"` / `"operator"` / `"system"` (v1.3) |
| `trace_id` | string | always | Non-null in nominal operation |
| `plugin_name` | string | always | Name of the plugin that wrote the marker (or last-known for OPERATOR_OVERRIDE/SUPERSEDED) |
| `artifact_path` | string | always | Path of the artifact that was being validated |
| `reason` | string | OPERATOR_OVERRIDE / SUPERSEDED: mandatory; null/absent otherwise | Description of operator action or supersession |
| `timestamp` | string (ISO8601) | always | Emission timestamp |

## Source Contract

- **BC:** BC-1.18.003 §PC1 — REVALIDATED clear: PASS outcome for same plugin+artifact triggers
  marker delete + emit `marker.cleared(REVALIDATED, validator, trace_id, reason=null)`.
- **BC:** BC-1.18.003 §PC3 — OPERATOR_OVERRIDE retroactive reconciliation: RAW_DELETE_DETECTED
  → emit `marker.cleared(OPERATOR_OVERRIDE, operator, trace_id, reason=non-null)`.
- **BC:** BC-1.18.003 §PC4 — TTL_EXPIRED clear with loudness: `expires_at <= now` → marker
  auto-delete + emit `marker.cleared(TTL_EXPIRED, deadman, trace_id, reason=null)`.
- **BC:** BC-1.18.003 §EC-014 — crash-path native TTL-allow does NOT emit `marker.cleared`.
- **BC:** BC-1.18.001 INV3 (v1.3 addition) — SUPERSEDED clear: cross-pair marker overwrite under
  single-marker last-writer-wins → emit `marker.cleared(SUPERSEDED, system, superseded pair's own
  trace_id, reason=non-null)` before the overwrite completes.
- **BC:** BC-3.08.001 Event 9 — `marker.cleared` wire format: eight mandatory fields; `reason`
  conditional (non-null for OPERATOR_OVERRIDE and — v1.3 — SUPERSEDED, absent/null for others).
- **ADR:** ADR-048 §Decision 4 — Audited Clear Event: introduces `marker.cleared` as the 9th
  dispatcher domain event; defines three `clear_mode` values and `actor_type` mapping; mandates
  TTL-loudness (TTL auto-expiry now emits audited event); defines RAW_DELETE_DETECTED
  reconciliation for OPERATOR_OVERRIDE.
- **ADR:** ADR-048 §Decision 4 v1.3 Emission-Mechanism Precision Correction (S-25.01 LOCAL
  adversary pass 3 F-P3-001 MEDIUM + F-P3-002 LOW) — ALL FOUR `clear_mode` emissions go via
  `ctx.emit_internal(ev)` (`ctx: &HostContext`), never a raw `InternalLog::write` and never the
  WASM `emit_event` host ABI; `reconcile_raw_delete`'s scan target is `dispatcher-internal-{date}
  .jsonl` (via `InternalLog`), not a literal `events-*.jsonl`; adds `clear_mode = "SUPERSEDED"` /
  `actor_type = "system"` emitted by `write_indeterminate_marker`'s caller at cross-pair overwrite.
- **ADR:** ADR-048 §Decision 4 v1.2 Emission-Point Correction (S-25.01 LOCAL adversary pass 2
  F-P2-002 HIGH + F-P2-003 MED) — ALL THREE `clear_mode` emissions are dispatcher-native
  (`emit_marker_cleared` in `indeterminate_marker.rs`), never emitted from inside the WASM gate
  plugin via `emit_event` (RESERVED_FIELDS enrichment makes a foreign trace_id/plugin_name
  structurally unachievable from WASM). TTL_EXPIRED is detected+cleared by
  `check_and_clear_expired_marker` (new); OPERATOR_OVERRIDE is detected+reconciled by
  `reconcile_raw_delete` (new) — both run in `executor.rs`'s tier-execution loop before invoking
  the Arm 1/Arm 2 plugin on the normal path. `guard_logic::evaluate_gate` no longer contains any
  TTL or emission logic.

## Proof Method

| Method | Tool | Bounded? | Coverage |
|--------|------|----------|----------|
| unit-test | Rust (#[test] within dispatcher crate) | yes — 5 test functions | (PC1) REVALIDATED path: `delete_marker_if_pass` with valid marker + matching PostToolUse PASS outcome, followed by `emit_marker_cleared(ctx, ...)` at the `executor.rs` callsite → `ctx.drain_events()` yields one `marker.cleared` with `clear_mode=REVALIDATED`, `actor_type=validator`, `reason=null`; (PC2) TTL_EXPIRED path: `check_and_clear_expired_marker(factory_root, now, ctx)` with expired `expires_at` → `ctx.drain_events()` yields one `marker.cleared` with `clear_mode=TTL_EXPIRED`, `actor_type=deadman`, `reason=null` [v1.2: emission call corrected to `ctx.emit_internal`, per ADR-048 §D4 v1.3]; (PC3) OPERATOR_OVERRIDE path: `reconcile_raw_delete(factory_root, ctx)` RAW_DELETE_DETECTED reconciliation, scanning a fixture `dispatcher-internal-{date}.jsonl` (not `events-*.jsonl`) → `ctx.drain_events()` yields one `marker.cleared` with `clear_mode=OPERATOR_OVERRIDE`, `actor_type=operator`, `reason=non-null` [v1.2: scan-target + emission corrected per ADR-048 §D4 v1.3]; (PC4) crash-path native-TTL-allow: `block_if_marker_check` with expired marker → returns Allow, `ctx.drain_events()` yields ZERO `marker.cleared` events; (PC5, NEW) SUPERSEDED path: `write_indeterminate_marker`'s caller, given an existing marker for a DIFFERENT `(plugin_name, artifact_path)` pair, overwrites it → `ctx.drain_events()` yields one `marker.cleared` with `clear_mode=SUPERSEDED`, `actor_type=system`, `reason=non-null`, carrying the SUPERSEDED pair's own fields (not the new pair's) |

### Why unit-test

All five postconditions are verifiable as pure unit tests using the SAME `HostContext::new(...)`
+ `ctx.drain_events()` harness already proven for the rest of the BC-3.08.001 catalog (e.g.
`host/emit_event.rs`'s `test_BC_3_08_001_s19_05_t003a_...`):
- PC1/PC2/PC3/PC5 construct a `HostContext` (with `internal_log: Some(Arc::new(InternalLog::new
  (tempdir)))` where the function under test also needs a durable log — PC3 and PC5's file-backed
  fixtures in particular), call the function under test, then call `ctx.drain_events()` and assert
  on the returned `Vec<InternalEvent>`'s `type_`/`fields`. `HostContext::emit_internal` is
  deterministic given its inputs (takes data in, produces/queues an event) — no WASM invocation,
  no network, no non-determinism.
- PC4 tests that `block_if_marker_check` (dispatcher native check) does NOT call
  `emit_internal`/`emit_marker_cleared` — verifiable by asserting `ctx.drain_events()` is empty
  after the call.

No end-to-end bats harness is required for these structural emission properties. The integration
harness for VP-079 Event 9 will extend to cover the full dispatch-chain emission of
`marker.cleared` in Phase-6 formal hardening (consistent with VP-079's SITE_8 scope note
pattern for new event types).

## Proof Harness Skeleton

```rust
// crates/factory-dispatcher/src/tests/vp_108_marker_cleared_event.rs
// VP-108 v1.2: BC-1.18.001 INV3 + BC-1.18.003 §PC1/PC3/PC4 + BC-3.08.001 Event 9 + ADR-048 §D4 v1.3
// marker.cleared audited-clear event emission correctness.
//
// Harness note (v1.2 correction): there is no `CapturingSink`/`MarkerClearedEvent` type in this
// crate. The real capture mechanism is `HostContext::drain_events()` — the SAME harness already
// proven for every other BC-3.08.001 dispatcher-native event in `host/emit_event.rs` (e.g.
// `test_BC_3_08_001_s19_05_t003a_...`). `HostContext::emit_internal` writes to `InternalLog` when
// `ctx.internal_log` is `Some` AND pushes onto `ctx.events`, drained via `ctx.drain_events()`.

#[cfg(test)]
mod vp_108 {
    use super::*;
    use crate::host::HostContext;
    use crate::indeterminate_marker::{
        block_if_marker_check, check_and_clear_expired_marker, delete_marker_if_pass,
        emit_marker_cleared, read_all_marker_fields, reconcile_raw_delete, MarkerFields,
    };
    use crate::internal_log::InternalLog;
    use std::fs;
    use std::sync::Arc;

    /// Build a HostContext wired to a real, file-backed InternalLog rooted at `dir/logs`, so
    /// `emit_internal`'s InternalLog write and `reconcile_raw_delete`'s scan both operate on the
    /// SAME durable dispatcher-internal-{date}.jsonl file a real dispatch would use.
    fn test_ctx(dir: &std::path::Path, session_id: &str) -> HostContext {
        let mut ctx = HostContext::new("test-plugin", "0.0.0", session_id, "test-trace-vp108");
        ctx.internal_log = Some(Arc::new(InternalLog::new(dir.join("logs"))));
        ctx
    }

    /// Postcondition 1 (BC-1.18.003 §PC1): REVALIDATED clear emits marker.cleared correctly.
    /// Same plugin+artifact_path PASS outcome → delete marker, then the executor.rs callsite
    /// reads the pre-delete fields and calls emit_marker_cleared(ctx, ...) — delete_marker_if_pass
    /// itself does NOT emit; it only reports whether it removed the file (VP-108 v1.1 correction,
    /// unchanged by v1.2).
    #[test]
    fn test_revalidated_clear_emits_marker_cleared() {
        let dir = tempfile::tempdir().unwrap();
        let marker_path = dir.path().join("unvalidated-mutation.marker");
        let fields = MarkerFields {
            timestamp: "2026-08-31T00:00:00Z".to_string(),
            plugin_name: "regression-gate".to_string(),
            artifact_path: "/tmp/.factory/STATE.md".to_string(),
            cause: "fuel".to_string(),
            trace_id: "deadbeef-0108-0001-0001-000000000001".to_string(),
            expires_at: "2099-01-01T00:00:00Z".to_string(),
        };
        crate::indeterminate_marker::write_indeterminate_marker(&fields, &marker_path).unwrap();

        let ctx = test_ctx(dir.path(), "session-vp108-pc1");
        // Callsite pattern mirrors executor.rs: read fields BEFORE delete for provenance.
        let all_fields = read_all_marker_fields(&marker_path).unwrap();
        let removed = delete_marker_if_pass(&marker_path, "/tmp/.factory/STATE.md").unwrap();
        assert!(removed, "VP-108 PC1: delete_marker_if_pass must report removal");
        if let Some(ref f) = all_fields {
            emit_marker_cleared(&ctx, f, "REVALIDATED", "validator", None);
        }

        let events = ctx.drain_events();
        assert_eq!(events.len(), 1, "VP-108 PC1: exactly one marker.cleared event must be emitted");
        let ev = &events[0];
        assert_eq!(ev.type_, "marker.cleared", "VP-108 PC1: type must be 'marker.cleared'");
        assert_eq!(
            ev.fields.get("clear_mode").and_then(|v| v.as_str()),
            Some("REVALIDATED"),
            "VP-108 PC1: clear_mode must be 'REVALIDATED'"
        );
        assert_eq!(
            ev.fields.get("actor_type").and_then(|v| v.as_str()),
            Some("validator"),
            "VP-108 PC1: actor_type must be 'validator'"
        );
        assert_eq!(
            ev.dispatcher_trace_id.as_deref(),
            Some(fields.trace_id.as_str()),
            "VP-108 PC1: trace_id must be the marker's own trace_id"
        );
        assert_eq!(ev.plugin_name.as_deref(), Some("regression-gate"));
        assert_eq!(
            ev.fields.get("artifact_path").and_then(|v| v.as_str()),
            Some("/tmp/.factory/STATE.md")
        );
        assert!(
            ev.fields.get("reason").is_none_or(|v| v.is_null()),
            "VP-108 PC1: reason must be null/absent for REVALIDATED"
        );
        assert!(!marker_path.exists(), "VP-108 PC1: marker must be deleted after REVALIDATED clear");
    }

    /// Postcondition 2 (BC-1.18.003 §PC4 + ADR-048 §D4 v1.3 TTL-loudness):
    /// TTL_EXPIRED clear emits marker.cleared via ctx.emit_internal (v1.2 — NOT a raw
    /// InternalLog::write, per ADR-048 §D4 v1.3 F-P3-001).
    #[test]
    fn test_ttl_expired_clear_emits_marker_cleared() {
        let dir = tempfile::tempdir().unwrap();
        let marker_path = dir.path().join("unvalidated-mutation.marker");
        let fields = MarkerFields {
            timestamp: "2020-01-01T00:00:00Z".to_string(),
            plugin_name: "regression-gate".to_string(),
            artifact_path: "/tmp/.factory/STATE.md".to_string(),
            cause: "fuel".to_string(),
            trace_id: "deadbeef-0108-0002-0002-000000000002".to_string(),
            expires_at: "2020-01-02T00:00:00Z".to_string(),
        };
        crate::indeterminate_marker::write_indeterminate_marker(&fields, &marker_path).unwrap();

        let ctx = test_ctx(dir.path(), "session-vp108-pc2");

            .unwrap()
            .with_timezone(&chrono::Utc);
        // v1.2 (ADR-048 §D4 v1.3): check_and_clear_expired_marker takes &HostContext, not a bare
        // &InternalLog + session_id pair — it calls ctx.emit_internal internally.
        let cleared = check_and_clear_expired_marker(dir.path(), now, &ctx)
            .expect("VP-108 PC2: check_and_clear_expired_marker must not error");
        assert!(cleared.is_some(), "VP-108 PC2: expired marker must be detected and cleared");

        assert_eq!(ev.type_, "marker.cleared");
        assert_eq!(ev.fields.get("clear_mode").and_then(|v| v.as_str()), Some("TTL_EXPIRED"));
        assert_eq!(ev.fields.get("actor_type").and_then(|v| v.as_str()), Some("deadman"));
        assert_eq!(
            ev.dispatcher_trace_id.as_deref(),
            Some(fields.trace_id.as_str()),
            "VP-108 PC2: trace_id must be the MARKER's own trace_id, not the current dispatch's"
        );
        assert!(ev.fields.get("reason").is_none_or(|v| v.is_null()));
        assert!(!marker_path.exists(), "VP-108 PC2: expired marker must be auto-deleted");

    /// Postcondition 3 (BC-1.18.003 §PC3 + ADR-048 §D4 v1.3 RAW_DELETE_DETECTED):
    /// OPERATOR_OVERRIDE clear emits marker.cleared with non-null reason. Scan target (v1.2

    /// plugin.indeterminate record to THAT file (via ctx.emit_internal), not to any

    #[test]
    fn test_operator_override_clear_emits_marker_cleared_with_reason() {
        let dir = tempfile::tempdir().unwrap();
        let ctx = test_ctx(dir.path(), "session-vp108-pc3");
        // Seed an unmatched plugin.indeterminate (fail-closed) record via the SAME
        // ctx.emit_internal path production code uses — lands in
        // dispatcher-internal-{today}.jsonl, which reconcile_raw_delete scans.
        let ev = crate::internal_log::InternalEvent::now("plugin.indeterminate")
            .with_trace_id("deadbeef-0108-0003-0003-000000000003")
            .with_session_id("session-vp108-pc3")
            .with_plugin_name("regression-gate")
            .with_field("artifact_path", "/tmp/.factory/STATE.md")
            .with_field("cause", "fuel")

        assert!(!dir.path().join("unvalidated-mutation.marker").exists());

                .is_some_and(|r| !r.is_empty()),

    /// Postcondition 4 (BC-1.18.003 §EC-014):

    #[test]
    fn test_crash_path_native_ttl_allow_does_not_emit_marker_cleared() {

    /// Postcondition 5 (NEW — BC-1.18.001 INV3 cross-pair overwrite; ADR-048 §D4 v1.3;
    /// S-25.01 pass-3 F-P3-002 LOW): SUPERSEDED clear emitted when a marker for a DIFFERENT
    /// (plugin_name, artifact_path) pair is overwritten before being cleared.
    #[test]
    fn test_superseded_clear_emits_marker_cleared_for_overwritten_pair() {
        let dir = tempfile::tempdir().unwrap();
        let marker_path = dir.path().join("unvalidated-mutation.marker");
        let pair_a = MarkerFields {
            timestamp: "2026-08-31T00:00:00Z".to_string(),
            plugin_name: "plugin-a".to_string(),
            artifact_path: "/tmp/A.md".to_string(),
            cause: "fuel".to_string(),
            trace_id: "deadbeef-0108-0005-0005-00000000000a".to_string(),
            expires_at: "2099-01-01T00:00:00Z".to_string(),
        };
        crate::indeterminate_marker::write_indeterminate_marker(&pair_a, &marker_path).unwrap();

        let ctx = test_ctx(dir.path(), "session-vp108-pc5");
        // Implementer directive: the write_indeterminate_marker CALLER (executor.rs) reads the
        // pre-existing marker, detects the (plugin_name, artifact_path) mismatch against the NEW
        // pair about to be written, and emits SUPERSEDED for the OLD pair before overwriting.
        let existing = read_all_marker_fields(&marker_path).unwrap();
        let pair_b = MarkerFields {
            timestamp: "2026-08-31T01:00:00Z".to_string(),
            plugin_name: "plugin-b".to_string(),
            artifact_path: "/tmp/B.md".to_string(),
            cause: "epoch".to_string(),
            trace_id: "deadbeef-0108-0005-0005-00000000000b".to_string(),
            expires_at: "2099-01-01T01:00:00Z".to_string(),
        };
        if let Some(ref old) = existing
            && (old.plugin_name != pair_b.plugin_name || old.artifact_path != pair_b.artifact_path)
        {
            emit_marker_cleared(
                &ctx,
                old,
                "SUPERSEDED",
                "system",
                Some(
                    "SUPERSEDED: marker overwritten by a new plugin.indeterminate event for a \
                     different (plugin_name, artifact_path) pair before being cleared; \
                     last-writer-wins (BC-1.18.001 INV3)",
                ),
            );
        }
        crate::indeterminate_marker::write_indeterminate_marker(&pair_b, &marker_path).unwrap();

        let events = ctx.drain_events();
        assert_eq!(events.len(), 1, "VP-108 PC5: exactly one marker.cleared(SUPERSEDED) event");
        let ev = &events[0];
        assert_eq!(ev.fields.get("clear_mode").and_then(|v| v.as_str()), Some("SUPERSEDED"));
        assert_eq!(ev.fields.get("actor_type").and_then(|v| v.as_str()), Some("system"));
        assert_eq!(
            ev.dispatcher_trace_id.as_deref(),
            Some(pair_a.trace_id.as_str()),
            "VP-108 PC5: trace_id must be the SUPERSEDED (old) pair's own trace_id, not the new pair's"
        );
        assert_eq!(ev.plugin_name.as_deref(), Some("plugin-a"));
        assert_eq!(
            ev.fields.get("artifact_path").and_then(|v| v.as_str()),
            Some("/tmp/A.md")
        );
        assert!(
            ev.fields
                .get("reason")
                .and_then(|v| v.as_str())
                .is_some_and(|r| !r.is_empty()),
            "VP-108 PC5: reason MUST be non-null for SUPERSEDED"
        );
    }
```
