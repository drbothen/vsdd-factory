# VP-127: BC-INDEX First-Level Shard Addressing Is Zero-Lookup — A Pure Function of the BC-ID Prefix, No Manifest Read for Non-Sub-Sharded Subsystems

## Property Statement

Mechanism B2's common case — looking up which subsystem shard holds a given `BC-X.YY.NNN` — is a
pure computation, not a file read.

1. **Zero-lookup first-level addressing.** For a BC in a non-sub-sharded subsystem, the shard path
   `shards/BC-INDEX-SS-NN.md` is computed directly from the BC-ID's numeric prefix (`BC-X` →
   `SS-NN` via the ARCH-INDEX Subsystem Registry mapping) with ZERO reads of the shard-manifest,
   ZERO reads of `BC-INDEX.md`, and no read of ARCH-INDEX beyond the already-authoritative
   Subsystem Registry (BC-1.18.010 §Postcondition 2).

2. **Manifest-read-free invariant.** Any first-level lookup implementation that reads
   `BC-INDEX.shard-manifest.toml` before computing a single non-sub-sharded BC's shard path is a
   defect relative to this VP's zero-lookup postcondition (BC-1.18.010 §Invariant 1) — the manifest
   is needed ONLY for whole-corpus scans and second-level (sub-sharded) lookups (VP-128).

Verified with a mock filesystem read-counter asserting zero manifest reads for lookups into the
eight non-sub-sharded subsystems (SS-01/02/03/04/07/08/09/10).

### Why unit-test

The computation is a pure total function of a BC-ID and a small mapping table; the zero-read claim
is naturally asserted with a mock FS read counter over the enumerable set of non-sub-sharded
subsystems. Deterministic and fully covered by hand-crafted cases.

## Proof Harness Skeleton

```rust
// crates/factory-dispatcher/tests/bcindex_first_level_addressing_test.rs
// VP-127: BC-1.18.010 PC2/INV1

#[test]
fn test_BC_1_18_010_PC2_first_level_is_zero_lookup() {
    let fs = MockFs::counting();
    let path = shard_manager::resolve_subsystem_shard_path("BC-1.18.005", &fs);
    assert_eq!(path, "shards/BC-INDEX-SS-01.md");
    assert_eq!(fs.reads_of("BC-INDEX.shard-manifest.toml"), 0);   // zero manifest reads
    assert_eq!(fs.reads_of("BC-INDEX.md"), 0);
}

#[test]
fn test_BC_1_18_010_INV1_no_manifest_read_for_non_subsharded_subsystems() {
    let fs = MockFs::counting();
    for bc in ["BC-1.01.001","BC-2.01.001","BC-3.01.001","BC-4.01.001",
               "BC-7.01.001","BC-8.01.001","BC-9.01.001","BC-10.01.001"] {
        shard_manager::resolve_subsystem_shard_path(bc, &fs);
    }
    assert_eq!(fs.reads_of("BC-INDEX.shard-manifest.toml"), 0);
}
```
