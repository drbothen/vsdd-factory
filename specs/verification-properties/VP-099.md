# VP-099: hooks-registry Tool-Filter Anchoring Invariant — Every tool= Value Starts With ^ or Carries # intent: Comment

## Property Statement

Every `tool =` value in `plugins/vsdd-factory/hooks-registry.toml` MUST satisfy at least one of:

1. **Starts with `^`** — a regex-anchored tool filter (e.g., `tool = "^Write"`, `tool = "^Bash"`)
   that binds to a specific tool name with no prefix ambiguity.
2. **No `tool =` field** — the hook fires on all tools (explicit wildcard intent, documented in
   the entry's `name` field).
3. **Carries `# intent:` comment on the same line or immediately preceding** — for any `tool =`
   value not starting with `^`, a `# intent:` comment MUST document the deliberate unanchored
   choice.

Unanchored bare substrings (e.g., `tool = "Edit"`) match unexpected tool names (e.g., a future
`BulkEdit` tool) and cause false-positive hook triggers. This invariant enforces that every
non-wildcard tool filter is anchored at the pattern start.

### Why integration (grep-based)

The property is a structural invariant over the static registry file. A bats test running grep
against the live `hooks-registry.toml` is both sufficient and fast (<50ms). No dispatcher binary
invocation needed. Same approach as VP-078.

## Proof Harness Skeleton

```bash
#!/usr/bin/env bats
# vp099-tool-filter-anchoring.bats
# VP-099: hooks-registry tool-filter anchoring invariant

REGISTRY="${CLAUDE_PROJECT_DIR:-$(git rev-parse --show-toplevel)}/plugins/vsdd-factory/hooks-registry.toml"

@test "VP-099: all tool= values start with ^ or have # intent: comment" {
    [ -f "$REGISTRY" ] || skip "hooks-registry.toml not found at $REGISTRY"

    local failures=0
    while IFS= read -r line; do
        if echo "$line" | grep -qE '^\s*tool\s*='; then
            local value
            value=$(echo "$line" | sed -E 's/.*tool\s*=\s*"([^"]*)".*/\1/')
            # Anchored (starts with ^) or has # intent: annotation on same line
            if ! echo "$value" | grep -q '^[\^]'; then
                if ! echo "$line" | grep -q '# intent:'; then
                    echo "UNANCHORED: $line"
                    failures=$((failures + 1))
                fi
            fi
        fi
    done < "$REGISTRY"

    [ "$failures" -eq 0 ] || {
        echo "FAIL: $failures unanchored tool= value(s) in hooks-registry.toml"
        return 1
    }
}

@test "VP-099: no bare 'Edit' substring (would also match BulkEdit)" {
    [ -f "$REGISTRY" ] || skip "hooks-registry.toml not found at $REGISTRY"
    local bare_edit
    bare_edit=$(grep -n 'tool\s*=\s*"Edit"' "$REGISTRY" || true)
    [ -z "$bare_edit" ] || {
        echo "FAIL: bare 'Edit' filter found (matches MultiEdit/BulkEdit too): $bare_edit"
        return 1
    }
}

@test "VP-099: no bare 'Write' substring (would also match future BulkWrite)" {
    [ -f "$REGISTRY" ] || skip "hooks-registry.toml not found at $REGISTRY"
    local bare_write
    bare_write=$(grep -n 'tool\s*=\s*"Write"' "$REGISTRY" || true)
    [ -z "$bare_write" ] || {
        echo "FAIL: bare 'Write' filter found: $bare_write"
        return 1
    }
}
```
