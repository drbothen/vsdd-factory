# VP-099: hooks-registry Tool-Filter Anchoring Invariant — Every tool= Value Is Fully Anchored (^...$) or Carries # intent: Comment

## Property Statement

Every `tool =` value in `plugins/vsdd-factory/hooks-registry.toml` MUST satisfy at least one of:

1. **Fully anchored at both ends** — the value starts with `^` AND ends with `$` immediately
   before the closing quote (e.g., `tool = "^Write$"`, `tool = "^(Edit|Write|MultiEdit)$"`).
   A prefix-only pattern (e.g., `tool = "^Bash"`) is a violation: regex-SEARCH semantics mean
   `^Bash` still matches `BashAsync` as a substring, so the trailing `$` anchor is required.
2. **No `tool =` field** — the hook fires on all tools (explicit wildcard intent, documented in
   the entry's `name` field).
3. **Carries `# intent:` comment on the same line or immediately preceding** — for any `tool =`
   value not fully anchored at both ends, a `# intent:` comment MUST document the deliberate
   choice.

Unanchored bare substrings (e.g., `tool = "Edit"`) and prefix-only anchors (e.g., `tool = "^Bash"`)
both match unintended tool names under regex-SEARCH semantics (e.g., a future `BulkEdit` or
`BashAsync` tool) and cause false-positive hook triggers. This invariant enforces that every
non-wildcard tool filter is fully anchored at both ends.

### Why integration (grep-based)

The property is a structural invariant over the static registry file. A bats test running grep
against the live `hooks-registry.toml` is both sufficient and fast (<50ms). No dispatcher binary
invocation needed. Same approach as VP-078.

## Proof Harness Skeleton

```bash
#!/usr/bin/env bats
# vp099-tool-filter-anchoring.bats
# VP-099: hooks-registry tool-filter anchoring invariant (both-ends form)

REGISTRY="${CLAUDE_PROJECT_DIR:-$(git rev-parse --show-toplevel)}/plugins/vsdd-factory/hooks-registry.toml"

# AC-004 lint function: extract tool= values that are NOT fully anchored
# (missing leading ^ OR trailing $ before the closing quote) and carry no
# # intent: comment. Empty output = all entries compliant.
#
# FULLY-ANCHORED: value begins with ^ AND ends with $ immediately before the
# closing quote (either " or '). A prefix-only pattern (e.g., "^Bash") is a
# violation — regex-SEARCH still matches "BashAsync" as a substring.
#
# The [^"']* quantifier stops at the first quote character, preventing greedy-
# dot bypass via a comment-injected $ (e.g., tool = "^Edit" # note "$").
#
# The trailing "|| true" prevents propagating a non-zero exit from grep -v
# when all entries are compliant (grep -v returns 1 for "no lines matched").
_lint_tool_filter() {
    local toml="$1"
    grep -E '^tool = ' "$toml" \
      | grep -vE 'tool = ["'"'"']\^[^"'"'"']*\$["'"'"']' \
      | grep -vi '# *intent:' \
      || true
}

@test "VP-099: all tool= values are fully anchored (^...\$) or have # intent: comment" {
    [ -f "$REGISTRY" ] || skip "hooks-registry.toml not found at $REGISTRY"
    result=$(_lint_tool_filter "$REGISTRY")
    [ -z "$result" ] || {
        echo "FAIL: non-fully-anchored tool= value(s) in hooks-registry.toml:"
        echo "$result"
        return 1
    }
}

@test "VP-099: prefix-only anchor (^Bash, no trailing \$) is flagged as violation" {
    local fixture
    fixture=$(mktemp /tmp/vp099-fixture-XXXXXX.toml)
    printf 'tool = "^Bash"\n' > "$fixture"
    result=$(_lint_tool_filter "$fixture")
    rm -f "$fixture"
    # Lint must produce non-empty output — prefix-only anchor is a violation;
    # regex-SEARCH still matches "BashAsync" because the trailing $ is absent.
    [ -n "$result" ] || {
        echo "FAIL: _lint_tool_filter passed 'tool = \"^Bash\"' (no trailing \$);" \
             "prefix-only anchors still match BashAsync via regex-SEARCH"
        return 1
    }
}

@test "VP-099: no bare 'Edit' substring (would also match BulkEdit)" {
    [ -f "$REGISTRY" ] || skip "hooks-registry.toml not found at $REGISTRY"
    bare_edit=$(grep -n 'tool\s*=\s*"Edit"' "$REGISTRY" || true)
    [ -z "$bare_edit" ] || {
        echo "FAIL: bare 'Edit' filter found (matches MultiEdit/BulkEdit too): $bare_edit"
        return 1
    }
}

@test "VP-099: no bare 'Write' substring (would also match future BulkWrite)" {
    [ -f "$REGISTRY" ] || skip "hooks-registry.toml not found at $REGISTRY"
    bare_write=$(grep -n 'tool\s*=\s*"Write"' "$REGISTRY" || true)
    [ -z "$bare_write" ] || {
        echo "FAIL: bare 'Write' filter found: $bare_write"
        return 1
    }
}
```
