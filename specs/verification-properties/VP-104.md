# VP-104: INDETERMINATE for fail-closed Plugin Writes Unvalidated-Mutation Marker with Required Fields

## Property Statement

When a PostToolUse hook plugin with `failure_policy = FailClosed` produces an INDETERMINATE
outcome, the dispatcher MUST write a marker file at `.factory/unvalidated-mutation.marker`
containing ALL five required fields:

1. `timestamp` — ISO-8601 UTC timestamp of the INDETERMINATE event
2. `plugin_name` — the `name` field from the plugin's `[[hook]]` entry in hooks-registry.toml
3. `artifact_path` — the absolute path of the artifact written in the triggering PostToolUse event
4. `cause` — one of: `fuel`, `epoch`, or `output-too-large`
5. `trace_id` — the dispatcher trace ID of the event that produced INDETERMINATE

Required TOML format: the marker file MUST be parseable as valid TOML with the above five keys
at the top level.

Atomic write invariant: the marker file MUST be written atomically (write to a temp file in the
same directory, then rename), so no concurrent reader sees a partial marker.

Negative constraint (fail-open): A plugin with `failure_policy = FailOpen` that produces
INDETERMINATE MUST NOT write the marker file.

Negative constraint (PreToolUse): INDETERMINATE from a PreToolUse hook MUST NOT write the marker
file (PreToolUse blocks dispatch before any write occurs; the marker mechanism protects writes).

## Proof Method

| Method | Tool | Bounded? | Coverage |
|--------|------|----------|----------|
| unit-test | Rust (#[test] with tempdir) | yes — 5 cases | Required fields present + parseable TOML; correct cause mapping (fuel/epoch/output-too-large); fail-open no marker; atomic write (rename from temp); PreToolUse no marker |

### Why unit-test

The `write_indeterminate_marker` function (new module `crates/factory-dispatcher/src/indeterminate_marker.rs`)
takes `(dir: &Path, plugin_name: &str, artifact_path: &Path, cause: IndeterminateCause, trace_id: &str)`
and writes the marker. Tests use a `tempdir()` to capture output. No WASM runtime needed;
the marker write happens in the dispatcher's Rust code, not in the WASM plugin.

## Proof Harness Skeleton

```rust
// crates/factory-dispatcher/src/tests/vp_104_marker_write.rs
// VP-104: BC-1.18.001 PC4 — INDETERMINATE+fail-closed writes marker with required TOML fields

#[cfg(test)]
mod vp_104 {
    use super::*;
    use crate::indeterminate_marker::{write_indeterminate_marker, IndeterminateCause};
    use std::fs;
    use tempdir::TempDir;
    use toml::Value;

    fn read_marker(dir: &TempDir) -> Value {
        let marker_path = dir.path().join(".factory").join("unvalidated-mutation.marker");
        let content = fs::read_to_string(&marker_path)
            .expect("marker file must exist after INDETERMINATE+fail-closed");
        content.parse::<Value>()
            .expect("marker file must be valid TOML")
    }

    #[test]
    fn test_BC_1_18_001_marker_has_all_required_fields() {
        let dir = TempDir::new("vp104").unwrap();
        fs::create_dir_all(dir.path().join(".factory")).unwrap();
        let artifact_path = dir.path().join(".factory").join("STATE.md");

        write_indeterminate_marker(
            dir.path(),
            "regression-gate",
            &artifact_path,
            IndeterminateCause::Fuel,
            "deadbeef-0001-0001-0001-000000000001",
        ).expect("marker write must not fail");

        let marker = read_marker(&dir);
        assert!(marker.get("timestamp").is_some(), "VP-104: marker MUST have 'timestamp' field");
        assert!(marker.get("plugin_name").is_some(), "VP-104: marker MUST have 'plugin_name' field");
        assert!(marker.get("artifact_path").is_some(), "VP-104: marker MUST have 'artifact_path' field");
        assert!(marker.get("cause").is_some(), "VP-104: marker MUST have 'cause' field");
        assert!(marker.get("trace_id").is_some(), "VP-104: marker MUST have 'trace_id' field");
    }

    #[test]
    fn test_BC_1_18_001_cause_field_fuel_maps_to_correct_string() {
        let dir = TempDir::new("vp104_cause_fuel").unwrap();
        fs::create_dir_all(dir.path().join(".factory")).unwrap();
        let artifact_path = dir.path().join(".factory").join("STATE.md");

        write_indeterminate_marker(
            dir.path(),
            "convergence-tracker",
            &artifact_path,
            IndeterminateCause::Fuel,
            "aaaaaaaa-0000-0000-0000-000000000001",
        ).unwrap();

        let marker = read_marker(&dir);
        assert_eq!(marker["cause"].as_str().unwrap(), "fuel",
            "VP-104: IndeterminateCause::Fuel MUST serialize as 'fuel'");
    }

    #[test]
    fn test_BC_1_18_001_cause_field_output_too_large_maps_correctly() {
        let dir = TempDir::new("vp104_cause_otl").unwrap();
        fs::create_dir_all(dir.path().join(".factory")).unwrap();
        let artifact_path = dir.path().join(".factory").join("STATE.md");

        write_indeterminate_marker(
            dir.path(),
            "validate-burst-log-structure",
            &artifact_path,
            IndeterminateCause::OutputTooLarge,
            "bbbbbbbb-0000-0000-0000-000000000001",
        ).unwrap();

        let marker = read_marker(&dir);
        assert_eq!(marker["cause"].as_str().unwrap(), "output-too-large",
            "VP-104: IndeterminateCause::OutputTooLarge MUST serialize as 'output-too-large'");
    }

    #[test]
    fn test_BC_1_18_001_atomic_write_uses_rename() {
        // Verify write_indeterminate_marker uses atomic rename pattern:
        // check that no partially-written marker is observable by checking that the
        // function uses a temp file path during write.
        // Behavioral assertion: write succeeds and marker is readable immediately after return.
        let dir = TempDir::new("vp104_atomic").unwrap();
        fs::create_dir_all(dir.path().join(".factory")).unwrap();
        let artifact_path = dir.path().join(".factory").join("BURST.md");

        write_indeterminate_marker(
            dir.path(),
            "validate-cross-site-correspondence",
            &artifact_path,
            IndeterminateCause::Epoch,
            "cccccccc-0000-0000-0000-000000000001",
        ).unwrap();

        // Marker readable immediately post-write (rename-atomic guarantee)
        let marker_path = dir.path().join(".factory").join("unvalidated-mutation.marker");
        assert!(marker_path.exists(), "VP-104: marker MUST exist immediately after write_indeterminate_marker returns");
        // No temp file left behind
        let entries: Vec<_> = fs::read_dir(dir.path().join(".factory")).unwrap().collect();
        let temp_files: Vec<_> = entries.iter()
            .filter(|e| {
                let name = e.as_ref().unwrap().file_name();
                let name_str = name.to_string_lossy();
                name_str.starts_with(".unvalidated-mutation") || name_str.ends_with(".tmp")
            })
            .collect();
        assert!(temp_files.is_empty(),
            "VP-104: atomic write MUST NOT leave temp files in .factory/");
    }

    #[test]
    fn test_BC_1_18_001_marker_contains_correct_plugin_name_and_trace_id() {
        let dir = TempDir::new("vp104_fields").unwrap();
        fs::create_dir_all(dir.path().join(".factory")).unwrap();
        let artifact_path = dir.path().join(".factory").join("BC-INDEX.md");
        let expected_plugin = "validate-factory-path-staging";
        let expected_trace = "deadbeef-cafe-babe-cafe-000000000099";

        write_indeterminate_marker(
            dir.path(),
            expected_plugin,
            &artifact_path,
            IndeterminateCause::Fuel,
            expected_trace,
        ).unwrap();

        let marker = read_marker(&dir);
        assert_eq!(marker["plugin_name"].as_str().unwrap(), expected_plugin,
            "VP-104: plugin_name field MUST match the plugin that produced INDETERMINATE");
        assert_eq!(marker["trace_id"].as_str().unwrap(), expected_trace,
            "VP-104: trace_id field MUST match the dispatcher trace ID of the INDETERMINATE event");
    }
}
```
