# VP-122: Default Whole-Corpus Glob Never Matches Archived Shards; Missing or Corrupt Shard-Index Fails Loud

## Property Statement

1. **Default-glob exclusion.** The default whole-corpus glob pattern (`<stem>*.md` at the cycle
   root) never matches a path under `archive/<artifact-stem>/` (BC-1.18.007 §Postcondition 3). A
   whole-corpus reader without the explicit archive opt-in sees only active shards plus the current
   file — the honest `O(active)` behavior. Archived history is reachable only via an explicit second
   glob pass (`archive/<artifact-stem>/<stem>*.md`) or by consulting the shard-index directly.

2. **Fail-loud on missing/corrupt index.** If the shard-index is missing or malformed at the moment
   a retention check would run, the native gate returns `HookResult::Error` (taxonomy `E-SHD-002`)
   and the triggering write is blocked — retention/compaction MUST NOT silently skip its check and
   proceed as if no archival were needed (BC-1.18.007 §EC-005).

### Why unit-test

Glob-pattern matching against a known fixture directory tree and two deterministic error fixtures
(absent / malformed index) are exhaustively covered by hand-crafted cases; there is no input space a
generator meaningfully broadens.

// crates/factory-dispatcher/tests/shard_retention_glob_test.rs
// VP-122: BC-1.18.007 PC3/EC-005

#[test]
fn test_BC_1_18_007_PC3_default_glob_excludes_archive() {
    let tree = fixture_tree(active = ["decision-log.0009.md", "decision-log.md"],
                            archived = ["archive/decision-log/decision-log.0001.md"]);
    let hits = shard_manager::default_corpus_glob(&tree, "decision-log");
    assert!(hits.iter().all(|p| !p.contains("archive/")));
    assert_eq!(hits.len(), 2);                     // active + current only
}

#[test]
fn test_BC_1_18_007_EC005_missing_or_corrupt_index_is_error() {
    assert!(matches!(shard_manager::retention_check(&missing_index()),  HookResult::Error { .. }));
    assert!(matches!(shard_manager::retention_check(&malformed_index()), HookResult::Error { .. }));
}
