# VP-125: BC-INDEX changelog: Rotation Bounds the Live Sequence at N Items With Zero History Loss

## Property Statement

Mechanism B1 (BC-INDEX frontmatter `changelog:` auto-rotation) bounds the live frontmatter while
never losing history, over an arbitrary sequence of prepends.

1. **Bounded live sequence.** After any sequence of `changelog:` item prepends, the live
   frontmatter `changelog:` sequence never exceeds `N` items (BC-1.18.009 §Postcondition 1). `N` is
   a config value; the bound holds for any `N`. A single oversized changelog item still counts as
   exactly ONE item toward `N` (BC-1.18.009 §EC-004) — B1's rotation is item-count-triggered, not
   per-item-byte-triggered.

2. **No history loss.** Every `changelog:` item ever prepended remains recoverable (live in the
   frontmatter, or byte-for-byte in a sealed
   `BC-INDEX-changelog-shards/BC-INDEX-changelog.<seq:04>.md` shard). The total recoverable item
   count equals the total prepend count and is monotonically non-decreasing (BC-1.18.009
   §Postcondition 5, §Invariant 2). Reading all sealed shards in `seq` order followed by the live
   sequence reproduces the full history with no gaps or duplicates.

### Why proptest

Both are universal invariants over an arbitrary prepend sequence with a variable `N` — proptest's
generated sequences (including the oversized-single-item boundary case) cover the state space a
fixed fixture cannot. The rotation logic under test is `rotate_changelog` (reused, see VP-126); this
VP proves the observable bounded/lossless outcome of its automatic invocation.

## Proof Harness Skeleton

```rust
// crates/factory-dispatcher/tests/proptest_bcindex_changelog_rotation.rs
// VP-125: BC-1.18.009 PC1/PC5/INV2/EC-004

proptest! {
    #[test]
    fn prop_live_changelog_bounded((prepends, n) in arb_prepends_and_cap()) {
        let mut idx = SimBcIndex::with_changelog_cap(n);
        for item in prepends {
            idx.prepend_changelog_item(item);
            prop_assert!(idx.live_changelog_len() <= n);
        }
    }

    #[test]
    fn prop_no_changelog_history_loss(prepends in arb_prepends()) {
        let mut idx = SimBcIndex::with_changelog_cap(50);
        let mut count = 0;
        for item in prepends {
            idx.prepend_changelog_item(item);
            count += 1;
            prop_assert_eq!(idx.recoverable_item_count(), count);   // live + sealed shards
        }
    }
}
```
