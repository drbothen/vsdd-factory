# VP-126: BC-INDEX changelog: Rotation Reuses rotate_changelog/prepend_changelog_item — No Reimplemented Rotation Logic in shard_manager.rs

## Property Statement

Mechanism B1's rotation is a *caller* of the already-shipped primitives, not a reimplementation —
the "reuse, don't reinvent" guarantee that makes B1 a low-risk extension rather than new rotation
logic.

1. **Reuse via library call.** On `changelog:` overflow, `shard_manager.rs`'s B1 handler invokes
   `rotate_changelog` (`crates/last-amended-migrate/src/rotate.rs`) and `prepend_changelog_item`
   (`crates/last-amended-migrate/src/changelog.rs`) as library calls (BC-1.18.009 §Postcondition 2).

2. **No reimplemented rotation logic.** `shard_manager.rs`'s B1 handler contains NO
   changelog-rotation logic other than those calls (BC-1.18.009 §Invariant 1): it does not
   re-derive the tail-selection, sealed-shard-filename, or item-move logic that
   `rotate_changelog`/`prepend_changelog_item` already own. This is enforced by a static scan of the
   B1 handler for duplicated rotation logic and a check that the `factory-dispatcher` →
   `last-amended-migrate` dependency edge is present (and acyclic, per ADR-051 §Decision 8).

## Source Contract

- **BC:** BC-1.18.009 §Postcondition 2, §Invariant 1.

### Why static-check

"Reuse not reimplement" is a structural, source-level invariant best enforced by the cheapest
mechanism — a CI grep asserting the B1 handler's rotation path resolves to the imported library
functions and contains no duplicated rotation logic (the same class of enforcement as VP-061 agent-
prompt-discipline presence). A behavioral test cannot distinguish "rotated correctly via reuse" from
"rotated correctly via a copy of the logic"; the static check is the right tool for the non-
duplication guarantee.

## Proof Harness Skeleton

```bash
# ci/checks/vp126_bcindex_rotation_reuse.sh
# VP-126: BC-1.18.009 PC2/INV1 — reuse, don't reimplement

set -euo pipefail
SM=crates/factory-dispatcher/src/shard_manager.rs

# (1) B1 handler must call the shipped primitives.
grep -qE 'rotate_changelog|prepend_changelog_item' "$SM" || { echo "FAIL: B1 does not call the shipped primitives"; exit 1; }

# (2) B1 handler must NOT contain duplicated rotation logic (sealed-shard filename derivation,
#     tail-item selection) — those live only in last-amended-migrate.
if grep -qE 'BC-INDEX-changelog\.[0-9]{4}\.md|fn +rotate_|tail_items' "$SM"; then
  echo "FAIL: shard_manager.rs appears to reimplement changelog rotation"; exit 1
fi

# (3) dependency edge present (acyclic per ADR-051 D8).
grep -q 'last-amended-migrate' crates/factory-dispatcher/Cargo.toml || { echo "FAIL: missing dep edge"; exit 1; }
echo "PASS: VP-126 rotation reuse invariant holds"
```
