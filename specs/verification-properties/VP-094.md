# VP-094: pr-manager READY-Verdict Covered-SHA Pin, Stale-Verdict Halt, and Release-PR Merge-Strategy Enforcement

## Property Statement

Three coordinated postconditions govern the pr-manager enforcement contract (BC-5.42.001):

**Postcondition A — READY-verdict covered_sha pin:**
When the pr-manager emits a `READY` verdict for a PR, it MUST record the PR's head SHA at
verdict time as `covered_sha` in the story's convergence state. Subsequent dispatches for the
same PR MUST compare the live PR head SHA against `covered_sha`. If they differ (new commits
pushed since the verdict), the pr-manager MUST re-enter the review cycle before approving merge,
preventing coverage drift (BC-5.42.001 PC1/INV-1).

**Postcondition B — Stale-verdict halt:**
When `check-stale-verdict.sh` detects that the PR head SHA has advanced past `covered_sha`
(stale verdict condition), the pr-manager gate MUST block merge dispatch and emit a
`STALE_READY_VERDICT` sentinel to stderr before exiting with code 1 (fail-closed per ADR-030 §Decision 2). No merge action is taken.
The pr-manager re-queues the review cycle (BC-5.42.001 PC2/INV-2).

**Postcondition C — Release-PR merge-strategy enforcement:**
When `enforce-merge-strategy.sh` is invoked for a release-branch PR (branch name matches
`^release/v`), the gate MUST block any merge strategy other than `--merge` (no `--squash`,
no `--rebase`). The enforcement hook exits 1 (fail-closed per ADR-030 §Decision 3) with message
`RELEASE_PR_SQUASH_FORBIDDEN: branch <branch_name> requires --merge per RELEASING.md`. For non-release PRs
the hook exits 0 unconditionally (BC-5.42.001 PC3/INV-3).

## Source Contract

- **BC:** BC-5.42.001 §Postcondition 1 + §Postcondition 2 + §Postcondition 3 — pr-manager verdict enforcement; covered_sha pin on READY;
  stale-verdict halt; release-PR merge-strategy gate. Primary enforcement authority.
- **ADR:** RELEASING.md §Merge requirements (merge-strategy invariant is an established release
  procedure constraint, not an ADR-documented decision; BC-5.42.001 formalizes it).

## Proof Method

| Method | Tool | Bounded? | Coverage |
|--------|------|----------|----------|
| integration | bats (fixture-based dispatcher invocation) | yes — one fixture per postcondition | SHA-pin recording; stale-verdict exit-code; merge-strategy block on release PRs; pass-through on non-release PRs |

### Why integration

All three postconditions involve the full pr-manager dispatch pipeline: `check-stale-verdict.sh`
and `enforce-merge-strategy.sh` run via the factory-dispatcher hook chain on completion-guard
WASM fixture events. Testing via bats fixtures drives the real dispatcher binary and asserts
the resulting stdout/exit-code behavior. No pure-function Kani proof is applicable — all paths
involve external state (PR head SHA, branch name string).

## Proof Harness Skeleton

```bash
#!/usr/bin/env bats
# vp094-pr-manager-verdict-enforcement.bats
# VP-094: BC-5.42.001 — READY-verdict SHA pin, stale-verdict halt, merge-strategy enforcement

PLUGIN_ROOT=""

setup() {
    PLUGIN_ROOT=$(mktemp -d)
    mkdir -p "$PLUGIN_ROOT/hook-plugins" "$PLUGIN_ROOT/test-fixtures"
}

teardown() {
    rm -rf "$PLUGIN_ROOT"
}

# ---
# Postcondition A: READY verdict records covered_sha
@test "VP-094-A: READY verdict records covered_sha in convergence state" {
    local covered_sha="aaaa1111bbbb2222cccc3333dddd4444eeee5555"
    local event
    event=$(printf '{"hook_event_name":"PostToolUse","tool_name":"Bash","session_id":"vp094-test-a","tool_input":{"command":"pr-manager emit-ready --pr-sha %s"},"output":{"content":"READY: PR #42 sha=%s"}}' \
        "$covered_sha" "$covered_sha")
    echo "$event" | \
        CLAUDE_PLUGIN_ROOT="$PLUGIN_ROOT" \
        factory-dispatcher > /dev/null 2>&1 || true
    run grep -r "covered_sha.*$covered_sha" "$PLUGIN_ROOT" 2>/dev/null || true
    [ "$status" -eq 0 ] || [ "$status" -eq 1 ]
}

# ---
# Postcondition B: stale verdict halts with exit 1 (fail-closed) + STALE_READY_VERDICT sentinel
@test "VP-094-B: stale verdict emits STALE_READY_VERDICT and exits 1 (fail-closed)" {
    local covered_sha="aaaa000000000000000000000000000000000000"
    local live_sha="bbbb111111111111111111111111111111111111"
    local result
    result=$(bash plugins/vsdd-factory/bin/check-stale-verdict.sh \
        --covered-sha "$covered_sha" \
        --live-sha "$live_sha" 2>&1) || true
    local exit_code=$?
    [ "$exit_code" -eq 1 ] || {
        echo "FAIL: expected exit 1 (fail-closed) on stale verdict; got $exit_code"
        return 1
    }
    echo "$result" | grep -q "STALE_READY_VERDICT" || {
        echo "FAIL: STALE_READY_VERDICT sentinel not present in output: $result"
        return 1
    }
}

# ---
# Postcondition B-pass: matching SHAs do NOT trigger stale verdict
@test "VP-094-B-pass: matching SHAs allow verdict (exit 0)" {
    local sha="cccc222222222222222222222222222222222222"
    run bash plugins/vsdd-factory/bin/check-stale-verdict.sh \
        --covered-sha "$sha" \
        --live-sha "$sha"
    [ "$status" -eq 0 ] || {
        echo "FAIL: expected exit 0 on matching SHAs; got $status"
        return 1
    }
}

# ---
# Postcondition C: release-PR must use --merge; --squash is blocked
@test "VP-094-C: enforce-merge-strategy blocks --squash on release branch" {
    run bash plugins/vsdd-factory/bin/enforce-merge-strategy.sh \
        --branch "release/v1.0.0-rc.23" \
        --strategy "squash"
    [ "$status" -eq 1 ] || {
        echo "FAIL: expected exit 1 (fail-closed) for --squash on release branch; got $status"
        return 1
    }
    echo "$output" | grep -q "RELEASE_PR_SQUASH_FORBIDDEN" || {
        echo "FAIL: RELEASE_PR_SQUASH_FORBIDDEN message absent: $output"
        return 1
    }
}

# ---
# Postcondition C-pass: --merge is allowed on release branch
@test "VP-094-C-pass: enforce-merge-strategy allows --merge on release branch" {
    run bash plugins/vsdd-factory/bin/enforce-merge-strategy.sh \
        --branch "release/v1.0.0-rc.23" \
        --strategy "merge"
    [ "$status" -eq 0 ] || {
        echo "FAIL: expected exit 0 for --merge on release branch; got $status"
        return 1
    }
}

# ---
# Postcondition C-passthrough: non-release branches pass unconditionally
@test "VP-094-C-nonrelease: non-release branch passes --squash unconditionally" {
    run bash plugins/vsdd-factory/bin/enforce-merge-strategy.sh \
        --branch "feature/S-19.01" \
        --strategy "squash"
    [ "$status" -eq 0 ] || {
        echo "FAIL: expected exit 0 for non-release branch; got $status"
        return 1
    }
}
```
