# VP-098: Allowlisted-but-Absent File Returns internal.file_not_found Event and NOT_FOUND (-5); Zero CAPABILITY_DENIED False-Positives

## Property Statement

When a WASM plugin calls `host::read_file(path)` where `path` is within the declared
`path_allow` allowlist but the file does NOT exist on disk:

**Postcondition A — NOT_FOUND return code:**
`host::read_file` MUST return `codes::NOT_FOUND = -5` to the WASM plugin. It MUST NOT return
`CAPABILITY_DENIED = -1` (policy violation) or `OK = 0` with empty content. The caller-facing
distinction is: -5 means "path is allowed but file is missing"; -1 means "path is outside your
declared capability" (BC-2.07.001 PC2; ADR-025 Decision 13).

**Postcondition B — internal.file_not_found event:**
The dispatcher MUST emit an `internal.file_not_found` event to `events-*.jsonl` with fields
`plugin_name`, `path`, `trace_id` before returning -5 to the caller. Emit-then-return ordering:
event emitted before host function returns (BC-2.07.001 PC2).

**Postcondition C — zero false-positive CAPABILITY_DENIED:**
A plugin whose `path_allow` contains `[".factory/STATE.md"]` and calls
`host::read_file(".factory/NONEXISTENT.md")` (within-prefix path that doesn't exist) MUST
receive `NOT_FOUND = -5`, not `CAPABILITY_DENIED = -1`. The old conflation (returning -1 for
both absent and denied) is closed (BC-2.07.001 PC3; rc.22 smoke FINDING-2).

## Source Contract

- **BC:** BC-2.07.001 §Postcondition 2 + §Postcondition 3 — absent-but-allowlisted path semantics; NOT_FOUND (-5) code;
  `internal.file_not_found` event emission; zero false-positive CAPABILITY_DENIED.
- **ADR:** ADR-025 Decision 13 — `codes::NOT_FOUND = -5` allocation and purpose.

| Method | Tool | Bounded? | Coverage |

### Why integration

The property spans the dispatcher host layer (`read_file` implementation), the WASM plugin ABI,
and the event emission path. Unit tests of individual sub-functions do not catch wiring failures
between allowlist check, file-existence check, and return-code selection.

## Proof Harness Skeleton

```bash
#!/usr/bin/env bats
# vp098-read-file-not-found.bats
# VP-098: BC-2.07.001 — allowlisted-absent path returns NOT_FOUND (-5), not CAPABILITY_DENIED

setup() {
    PLUGIN_ROOT=$(mktemp -d)
    SINK_FILE=$(mktemp --suffix=.jsonl)
    mkdir -p "$PLUGIN_ROOT/hook-plugins"
    mkdir -p "$PLUGIN_ROOT/.factory"
    # vp098-probe.wasm: minimal WASM plugin that calls host::read_file and records return code
    # Implementation note: test-writer compiles vp098-probe.wasm from a dedicated Rust crate
}

teardown() {
    rm -rf "$PLUGIN_ROOT"
    rm -f "$SINK_FILE"
}

@test "VP-098-A: allowlisted-absent path returns NOT_FOUND (-5) not CAPABILITY_DENIED" {
    # Plugin has path_allow=[".factory/"], calls host::read_file(".factory/ABSENT.md")
    # ABSENT.md does not exist
    local result_code
    result_code=$(run_vp098_probe "$PLUGIN_ROOT" ".factory/ABSENT.md" "allowed")
    [ "$result_code" = "-5" ] || {
        echo "FAIL: expected NOT_FOUND (-5); got $result_code"
        return 1
    }
}

@test "VP-098-B: allowlisted-absent path emits internal.file_not_found event" {
    run_vp098_probe "$PLUGIN_ROOT" ".factory/ABSENT.md" "allowed" > /dev/null
    grep -q '"type":"internal.file_not_found"' "$SINK_FILE" || {
        echo "FAIL: internal.file_not_found event not emitted"; return 1
    }
    grep '"path".*ABSENT\.md' "$SINK_FILE" || {
        echo "FAIL: path field absent from internal.file_not_found event"; return 1
    }
}

@test "VP-098-C: path outside allowlist returns CAPABILITY_DENIED (-1) not NOT_FOUND" {
    # Plugin has path_allow=[".factory/"], calls host::read_file("/etc/passwd")
    local result_code
    result_code=$(run_vp098_probe "$PLUGIN_ROOT" "/etc/passwd" "denied")
    [ "$result_code" = "-1" ] || {
        echo "FAIL: expected CAPABILITY_DENIED (-1); got $result_code"
        return 1
    }
}

@test "VP-098-D: allowlisted-present path returns OK (0) with content" {
    echo "test content" > "$PLUGIN_ROOT/.factory/PRESENT.md"
    local result_code
    result_code=$(run_vp098_probe "$PLUGIN_ROOT" ".factory/PRESENT.md" "allowed")
    [ "$result_code" = "0" ] || {
        echo "FAIL: expected OK (0) for present allowlisted file; got $result_code"
        return 1
    }
}
```
