# VP-121: Retention Accounting Is Honest O(Active-Shards) — Bounded Active Count and No Shard-Index Entry Ever Lost

## Property Statement

Over an arbitrary sequence of seals and retention-driven archival moves against a simulated
artifact:

1. **Bounded active count.** After every seal, the number of NON-archived `[[shard]]` entries for
   the artifact is `<= retention_count` (BC-1.18.007 §Postcondition 2/§Postcondition 4). This is
   the honest `O(active shards)` bound ADR-047 §8b requires: the default whole-corpus scope never
   grows without bound. The property holds for `retention_count` lowered mid-flight (multiple
   archival moves in one invocation — §EC-002).

2. **No data loss.** Every `[[shard]]` entry ever created remains present in the shard-index (active
   or archived) — archival updates an entry's path (or sets `archived: true`) but never removes it
   (BC-1.18.007 §Postcondition 3, §Invariant 1, §Invariant 3). The lifetime shard-count derived from
   the index is monotonically non-decreasing across the whole sequence.

`retention_count` is a config value (default 10); the properties hold for any configured value, so
they are not F4-provisional.

### Why proptest

Both are universal invariants over arbitrary seal/archival sequences with a variable
`retention_count` — a generated-sequence property test covers the interleavings (including the
lower-mid-flight case) that a fixed fixture would miss.

## Proof Harness Skeleton

```rust
// crates/factory-dispatcher/tests/proptest_retention.rs
// VP-121: BC-1.18.007 PC2/PC3/PC4/INV1-3/EC-002

proptest! {
    #[test]
    fn prop_active_count_never_exceeds_retention((seals, ret) in arb_seal_sequence_and_retention()) {
        let mut art = SimArtifact::with_retention(ret);
        for s in seals {
            art.seal(s);
            prop_assert!(art.active_shard_count() <= art.retention_count());
        }
    }

    #[test]
    fn prop_lifetime_shard_count_monotonic(seals in arb_seal_sequence()) {
        let mut art = SimArtifact::with_retention(10);
        let mut prev = 0;
        for s in seals {
            art.seal(s);
            let now = art.index().shards.len();
            prop_assert!(now >= prev);            // no entry ever removed
            prev = now;
        }
    }
}
```
