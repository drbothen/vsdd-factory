# VP-092: check-state-health Reads CLAUDE_AUTOCOMPACT_PCT_OVERRIDE from Project-Local settings.json (Global Fallback), Emits ADVISORY When Absent or Value > 80, Emits PASS When Value <= 80, Never Blocks, Always Emits Check Row

## Property

The `check-state-health` skill extension for `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` verification MUST satisfy five provable properties under all settings.json configurations.

### §0 Structural Precondition — Read-Only, No Side Effects

**This precondition is load-bearing for all §1–§4 property semantics.**

The check is a passive read-only diagnostic. It reads `settings.json` from the resolved path (project-local preferred; global fallback) and inspects the `env` block. It performs NO writes, NO modifications, NO creates of any file, and emits NO events into the dispatcher log.

Per BC-6.25.001 Invariant 4 (no side effects): the check reads `settings.json` only. This precondition is guaranteed by BC-6.25.001 Invariant 4 and is verifiable by asserting that the filesystem state before and after skill invocation is identical (no new files, no modified files, no new dispatcher log entries from this check).

The path resolution order is fixed by BC-6.25.001 PC4:
- **Authoritative (project-local):** `.claude/settings.json` relative to the project root (directory containing `.factory/`).
- **Fallback (global):** `~/.claude/settings.json` — used ONLY when project-local is absent.
- **Neither present:** treated as key-absent (PC1 advisory fires with additional "no settings.json found" note per PC4(c)).

Per BC-6.25.001 Invariant 2 (precedence-stable): if both project-local and global files exist, the global file is never read for this check.

### §1 PC1 — Key Absent: Emits ADVISORY Row (BC-6.25.001 PC1)

When `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` is absent from the `env` block of the resolved `settings.json` (or no `settings.json` exists, or the `env` block is absent entirely), the skill MUST emit an advisory row.

- **Precondition:** Resolved `settings.json` exists but the `env.CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` key is absent. Covers: key absent from env block, env block absent, settings.json absent (both paths), non-integer value per Invariant 3 (treated as absent).
- **Postcondition (PC1):** The check table row for `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` carries `Status: ADVISORY`. The Details field contains the remediation hint: `Missing — add env: {CLAUDE_AUTOCOMPACT_PCT_OVERRIDE: "70"} to .claude/settings.json (ADR-026 §Decision 5: proactive compaction threshold; 70% gives PreCompact flush headroom)`. The advisory does NOT block any subsequent check or the overall skill output.

**Machine-stable assertion target (per L-F2-machine-stable-count-assertion):** The bats harness asserts the check table row for `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` using a structured sentinel — the skill MUST emit a row matching the check name exactly (`CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`) with status `ADVISORY`. The harness counts rows matching this check name with `ADVISORY` status (exactly 1). Row presence is the machine-stable signal; it is not a prose regex over free-form human output.

### §2 PC2 — Key Present, Value > 80: Emits ADVISORY Row (BC-6.25.001 PC2)

When `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` is present in the `env` block and its numeric value exceeds 80, the skill MUST emit an advisory row naming the actual value.

- **Precondition:** Resolved `settings.json` has `env.CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` present with a string value that parses as a decimal integer greater than 80 (e.g., `"85"`, `"100"`, `"81"`).
- **Postcondition (PC2):** The check table row carries `Status: ADVISORY`. The Details field contains: `Value <N> exceeds ADR-026 §Decision 5 ceiling of 80 (MEDIUM-confidence 83% harness cap); recommend 70 for safe PreCompact flush headroom` where `<N>` is the actual configured value. The advisory does NOT block.

**Machine-stable assertion target:** The bats harness asserts the check table row for `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` carries `ADVISORY` and that the actual value `<N>` appears in the Details string. The `<N>` token is the machine-stable discriminator between PC2 advisory rows (the actual value must match the fixture input).

### §3 PC3 — Key Present, Value <= 80: Emits PASS Row (BC-6.25.001 PC3)

When `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` is present and its numeric value is at or below 80, the skill MUST emit a PASS row and NO advisory.

- **Precondition:** Resolved `settings.json` has `env.CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` present with a string value that parses as a decimal integer at or below 80. Includes the boundary value 80 (EC-004) and the canonical value 70 (EC-001).
- **Postcondition (PC3):** The check table row carries `Status: PASS`. The Details field contains: `Present, value <N> <= 80 (70 is canonical per ADR-026 §Decision 5)`. No advisory row is emitted for this check.

**Machine-stable assertion target:** The bats harness asserts exactly one row for `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` in the check table with `PASS` status, and asserts no `ADVISORY` row for this check name in the same invocation output. The PASS/ADVISORY distinction is the machine-stable signal, not a prose regex over human-readable detail text.

### §4 PC4 — Path Resolution Precedence: Project-Local Takes Priority Over Global (BC-6.25.001 PC4)

When both `.claude/settings.json` (project-local) and `~/.claude/settings.json` (global) exist simultaneously, the skill MUST consult ONLY the project-local file and MUST NOT read the global file for this check.

- **Precondition:** Both `.claude/settings.json` (project-local, contains `env.CLAUDE_AUTOCOMPACT_PCT_OVERRIDE: "85"` — advisory value) and `~/.claude/settings.json` (global, contains `env.CLAUDE_AUTOCOMPACT_PCT_OVERRIDE: "70"` — PASS value) exist. This is BC-6.25.001 EC-010.
- **Postcondition (PC4):** The skill emits an ADVISORY row for `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` reflecting value 85 from the project-local file. It does NOT emit a PASS row reflecting the global file's value 70. The global file is not consulted.

**Machine-stable assertion target:** The bats harness uses two fixture files at the correct paths. It asserts the output carries `ADVISORY` (not `PASS`) for `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`, and that the Details string contains `85` (the project-local value), not `70` (the global value). The presence of the project-local value in the output is the machine-stable signal confirming path-precedence correctness.

### §5 PC5 + Invariant 1 — Advisory-Only, Never Blocks; Row Always Emitted (BC-6.25.001 PC5 + Invariant 1 + Invariant 5)

This check MUST NEVER cause the skill to exit non-zero, MUST NEVER set `block_intent=true`, and MUST NEVER prevent any downstream operation or E-18 skill. Furthermore, a check table row for `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` MUST ALWAYS appear in the output — PASS, ADVISORY, or error-notation — regardless of filesystem state.

- **Precondition (a):** Any settings.json state that produces an ADVISORY row (PC1 or PC2 conditions).
- **Postcondition (PC5-block):** The skill exits 0 (or with its normal HEALTHY/WARNINGS exit code). The `block_intent` field (if evaluated by any downstream consumer) is false. No downstream E-18 operation is prevented. The overall skill result MAY be elevated to `WARNINGS` when this advisory fires — consistent with check-state-health advisory escalation semantics per BC-6.25.001 PC5 — but MUST NOT reach `NEEDS-COMPACT` as a result of this advisory.

- **Precondition (b):** Any settings.json state (including no settings.json, parse error, key absent, key present PASS or ADVISORY).
- **Postcondition (always-row):** The check table in the skill output always contains a row with check name `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`. Silent omission is a specification violation per BC-6.25.001 Invariant 5.

**Machine-stable assertion target:** The bats harness asserts skill exit code 0 (or a defined non-blocking exit code). It also asserts the output contains exactly one row for `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` — this count (1) is the machine-stable signal. The count being 0 would indicate row-omission (Invariant 5 violation); the count being >1 would indicate row-duplication (an independent defect).

## Invariant Classification: Behavioral-Invariant (Advisory Mode; SS-06 Skill Catalog)

DI-020 is cited because this check verifies that the operator configuration prerequisite for the PreCompact flush safety net is in place. The `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE=70` setting enables proactive auto-compaction at 70% context utilization (ADR-026 §Decision 5), which gives the PreCompact flush hook sufficient headroom to complete before Claude Code's own compaction fires and potentially interrupts an in-progress flush. An unconfigured or misconfigured compaction threshold (`CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` absent, or value > 80) undermines the Part B (mid-wave compaction losslessness) arm of DI-020 ("Wave/phase boundary transitions must not lose load-bearing pipeline state").

This check is a PREVENTIVE-ADVISORY measure, consistent with BC-6.25.001 Invariant 1 (advisory-only, never blocking): it surfaces the misconfiguration risk to the operator without blocking any pipeline operation. The advisory-only constraint is the most critical property to verify: an implementation that blocks on misconfiguration would violate BC-6.25.001 Invariant 1 and introduce a silent regression risk against the DI-020 non-blocking advisory design.

Per L-F2-fix-at-correct-layer: every property in VP-092 is guaranteed by a BC-6.25.001 postcondition or invariant before being verified here. The upstream BC-6.25.001 guarantees are normative first; VP-092 verifies the implementation satisfies them.
