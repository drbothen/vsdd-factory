# VP-097: path_util::resolve_path_for_allowlist Traversal Defense — .. Sequences Cannot Resolve Outside Allowlist Prefixes

## Property Statement

The traversal defense is implemented by two cooperating functions in the shipped S-19.03 code:

- **`path_util::resolve_path_for_allowlist(target: &Path, canonicalize_fn) -> Option<PathBuf>`**
  — pure ancestor-walk and rejoin. Applies `canonicalize_fn` to find the deepest existing
  ancestor of `target`, then rejoins any remaining tail components as-is. Returns `None` when
  `target`'s path ends in `..` (because `cur.file_name()` returns `None` for any path whose
  last component is `..`, short-circuiting the function). By design, this function does NOT
  itself perform the allowlist check; it returns `Some` for any resolvable path. The "absent
  tail" (components past the deepest existing ancestor) is rejoined verbatim as `Normal` names,
  so the resolved path contains no `..` components (H1 below).
- **`host::path_util::check_path_allowed(target, allow, base, canonicalize_fn) -> PathAllowDecision`**
  — the shared `starts_with` containment gate (S-19.03 F-P2-001 hoist; covers both read_file and
  write_file paths). Resolves both `target` and each allowlist prefix, then checks that the
  resolved target is contained under a resolved prefix. Returns `PathAllowDecision::Allowed` only
  when containment holds; `PathAllowDecision::DeniedNotAllowed` otherwise.

The traversal defense invariant is verified by four Kani proofs:

**H1 (traversal safety):** For ANY target path structure, if `resolve_path_for_allowlist`
returns `Some(r)`, then `r` contains no `ParentDir` (`..`) components. This holds because the
resolver collects tail components via `cur.file_name()`, which returns `None` for any path
ending in `..`, short-circuiting the whole function to `None`. Every surviving tail is therefore
a `Normal` name, and `canonicalize_fn` output is `..`-free by contract. The absent tail is
rejoined verbatim as Normal names, so the resolved path contains no `..` components — consistent
with `file_name()` returning `None` on any `..`-terminated component, which short-circuits
`resolve` to `None` (per H1).

**H2 (containment):** `check_path_allowed` returns `Allowed` ONLY when the resolved target
`starts_with` a resolved allowlist prefix. No `Allowed` result may correspond to a path outside
all declared prefixes.

**H3 (escape witness + non-vacuity):** A concrete escaping path (`/r/b/s/../x` under
`allow=["/r/b/s"]`) is `DeniedNotAllowed` — the `..` collapses against the existing ancestor
`s` to yield `/r/b/x`, which fails the `starts_with` check. A concrete in-prefix path
(`/r/b/s`) is `Allowed`. Proves the property is not vacuously satisfied.

**H4 (determinism):** Two calls to `resolve_path_for_allowlist` on identical inputs under a
pure `canonicalize_fn` yield identical results. Underpins the soundness of H2's re-derivation.

Formally:
```
∀ target: &Path, ∀ canonicalize_fn (pure, deterministic):
  H1: resolve_path_for_allowlist(target, canonicalize_fn) = Some(r) →
        r.components().all(|c| c ≠ Component::ParentDir)

∀ target: &Path, ∀ allow: &[String], ∀ base: &Path:
  H2: check_path_allowed(target, allow, base, canonicalize_fn) = Allowed →
        ∃ prefix ∈ allow:
          resolve(target).starts_with(resolve(prefix))

  H3: check_path_allowed(/r/b/s/../x, ["/r/b/s"], /, model_cf) = DeniedNotAllowed
      ∧ check_path_allowed(/r/b/s,     ["/r/b/s"], /, model_cf) = Allowed

  H4: resolve_path_for_allowlist(t, cf) = resolve_path_for_allowlist(t, cf)
        (determinism under pure cf)
```

H1 + H2 together close the traversal vector: no `..` survives into a resolved path that passes
the containment check, so no `..`-escape is ever accepted. This property closes
BC-2.02.011 §EC-001 and BC-2.07.001 §Invariant 1.

### Why Kani

The traversal defense property is a safety invariant over all possible path inputs. Kani's
bounded model checking can exhaustively verify the rejoin algorithm for all paths up to a
bounded length. This is the correct tool for a security boundary property that cannot be
falsified by random sampling alone.

## Proof Harness Skeleton

The harness below matches the shipped implementation inlined in
`crates/factory-dispatcher/src/host/path_util.rs` as `#[cfg(kani)] mod kani_proofs { ... }`
(per the S-19.03 F-P3-001 inline-per-convention fix; matches `partition.rs`/`aggregator.rs` convention).
It supersedes the stale monolithic skeleton that targeted a pre-S-19.03 signature.

Symbolic input is the path STRUCTURE: a fixed existing base (`/r/b`) plus a symbolic tail of
up to `TAIL_MAX` components drawn from the vocabulary `["s", "x", "..", "."]`. Component
content is concrete; only which components appear and how many is symbolic, so Kani explores a
bounded tree of concrete path executions covering every traversal shape up to `TAIL_MAX` depth.
A pure, deterministic `model_canonicalize` replaces `std::fs::canonicalize` (which requires I/O
and cannot be model-checked); the model faithfully reproduces the two properties the real syscall
guarantees: (1) succeeds only for paths denoting existing objects, (2) returns `..`-free
absolute paths.

```rust
// File: crates/factory-dispatcher/src/host/path_util.rs (inline #[cfg(kani)] mod kani_proofs)
#![cfg_attr(not(kani), allow(unexpected_cfgs))]

#[cfg(kani)]
mod kani_proofs {
    use crate::host::path_util::check_path_allowed;
    use crate::host::path_util::{PathAllowDecision, resolve_path_for_allowlist};
    use std::path::{Component, Path, PathBuf};

    const TAIL_MAX: usize = 3;
    const COMPONENT_VOCAB: [&str; 4] = ["s", "x", "..", "."];

    /// Modeled filesystem: existing directories only.
    fn dir_exists(p: &Path) -> bool {
        matches!(
            p.to_str(),
            Some("/") | Some("/r") | Some("/r/b") | Some("/r/b/s")
        )
    }

    /// Pure, deterministic model of `std::fs::canonicalize` over the modeled filesystem.
    /// Succeeds iff `p` is absolute and denotes an existing object via existing directories.
    /// Returns a lexically-normalized, `..`-free absolute path (BC-2.07.001 §EC-007 seam).
    fn model_canonicalize(p: &Path) -> std::io::Result<PathBuf> {
        let not_found = || std::io::Error::from(std::io::ErrorKind::NotFound);
        let mut comps = p.components();
        match comps.next() {
            Some(Component::RootDir) => {}
            _ => return Err(not_found()),
        }
        let mut cur = PathBuf::from("/");
        for c in comps {
            match c {
                Component::CurDir => {}
                Component::ParentDir => {
                    if !dir_exists(&cur) { return Err(not_found()); }
                    cur.pop();
                }
                Component::Normal(name) => {
                    if !dir_exists(&cur) { return Err(not_found()); }
                    cur.push(name);
                }
                _ => return Err(not_found()),
            }
        }
        if !dir_exists(&cur) { return Err(not_found()); }
        Ok(cur)
    }

    fn any_component() -> &'static str {
        let idx: usize = kani::any();
        kani::assume(idx < COMPONENT_VOCAB.len());
        COMPONENT_VOCAB[idx]
    }

    fn symbolic_target() -> PathBuf {
        let n: usize = kani::any();
        kani::assume(n <= TAIL_MAX);
        let mut target = PathBuf::from("/r/b");
        for _ in 0..n { target.push(any_component()); }
        target
    }

    /// VP-097 H1 — traversal safety: a resolved path never contains `..`.
    /// If resolve returns Some(r), then r has zero ParentDir components.
    #[kani::proof]
    #[kani::unwind(20)]
    fn verify_resolved_path_has_no_parent_dir_component() {
        let target = symbolic_target();
        if let Some(resolved) = resolve_path_for_allowlist(&target, model_canonicalize) {
            let has_parent_dir = resolved.components()
                .any(|c| matches!(c, Component::ParentDir));
            kani::assert(
                !has_parent_dir,
                "VP-097 H1: resolved path must contain no `..` components \
                 (BC-2.07.001 Invariant 1)",
            );
        }
    }

    /// VP-097 H2 — containment gate: `Allowed` implies `starts_with` a prefix.
    /// check_path_allowed returns Allowed ONLY when resolved target is
    /// contained under a resolved allowlist prefix.
    #[kani::proof]
    #[kani::unwind(20)]
    fn verify_allowed_implies_starts_with_prefix() {
        let target = symbolic_target();
        let allow = ["/r/b/s".to_string()];
        let base = Path::new("/");
        let decision = check_path_allowed(&target, &allow, base, model_canonicalize);
        if matches!(decision, PathAllowDecision::Allowed) {
            let resolved = resolve_path_for_allowlist(&target, model_canonicalize)
                .expect("Allowed requires target to resolve to Some");
            let resolved_prefix =
                resolve_path_for_allowlist(Path::new("/r/b/s"), model_canonicalize)
                    .expect("Allowed requires prefix to resolve to Some");
            kani::assert(
                resolved.starts_with(&resolved_prefix),
                "VP-097 H2: Allowed only when resolved target starts_with resolved prefix \
                 (BC-2.02.011 EC-001 containment gate)",
            );
        }
    }

    /// VP-097 H3 — escape witness + non-vacuity.
    /// /r/b/s/../x is DeniedNotAllowed (.. escapes to /r/b/x outside /r/b/s).
    /// /r/b/s itself is Allowed (non-vacuity witness).
    #[kani::proof]
    #[kani::unwind(20)]
    fn verify_escape_is_denied_and_legit_is_allowed() {
        let allow = ["/r/b/s".to_string()];
        let base = Path::new("/");
        let escape_decision = check_path_allowed(
            Path::new("/r/b/s/../x"), &allow, base, model_canonicalize,
        );
        kani::assert(
            matches!(escape_decision, PathAllowDecision::DeniedNotAllowed),
            "VP-097 H3: /r/b/s/../x must be DeniedNotAllowed",
        );
        let legit_decision = check_path_allowed(
            Path::new("/r/b/s"), &allow, base, model_canonicalize,
        );
        kani::assert(
            matches!(legit_decision, PathAllowDecision::Allowed),
            "VP-097 H3: /r/b/s must be Allowed (non-vacuity witness)",
        );
    }

    /// VP-097 H4 — determinism under a pure canonicalize seam.
    #[kani::proof]
    #[kani::unwind(20)]
    fn verify_resolve_is_deterministic() {
        let target = symbolic_target();
        let r1 = resolve_path_for_allowlist(&target, model_canonicalize);
        let r2 = resolve_path_for_allowlist(&target, model_canonicalize);
        kani::assert(r1 == r2, "VP-097 H4: resolver must be deterministic");
    }
}
```
