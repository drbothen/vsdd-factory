### F-P6-001 — LOW — [doc-accuracy] — fixture main.rs module doc claims CapabilityDenied on wasm-target standalone execution — structurally impossible

**Severity:** LOW
**Class:** doc-accuracy
**Scope:** `crates/hook-plugins/read-prefix-fixture/src/main.rs` (module-level doc comment)
**Production impact:** None. Fixture is not executed in CI standalone wasm mode; the doc comment is dead documentation.

**Description:** The `read-prefix-fixture` crate `main.rs` module doc asserts (approximately) that when the fixture binary is instantiated in wasm-target mode without host linkage, the `vsdd::read_prefix` call returns `HostError::CapabilityDenied`. This claim is structurally impossible: under standalone wasm instantiation (no host function linkage provided), the `vsdd::read_prefix` import is unresolved at the wasmtime linker stage, causing `Linker::instantiate` to fail before any guest code runs. The fixture guest never reaches the `vsdd::read_prefix` call site; no return code is produced. The `−1/CapabilityDenied` mapping is surfaced only via the non-wasm `host_stubs` fallback path, which the fixture never reaches in the wasm-hosted execution model.

**Why it matters:** Under the production-grade default, a doc comment that claims behavior the code cannot exhibit is a correctness defect. A reader of the fixture doc would incorrectly infer that wasm-target standaloneinstantiation exercised the `CapabilityDenied` code path, which could mask a gap in understanding of the fixture's actual execution model. The fixture IS exercised via the bats suite under proper host linkage; the doc comment falsely implies a secondary standalone-capable test axis that does not exist.

**Routing decision:** Implementer fix-in-scope. Doc-only change: correct the module doc to accurately describe the fixture's execution model (requires host linkage; standalone wasm instantiation without host functions fails at the linker stage). Full gate re-verify at corrected HEAD before pass-7.

**Status:** OPEN — ROUTED implementer fix-in-scope (in flight)
