### O-1 (LOW — non-blocking, POLICY 13)

**ifs_step2_re `(`-prefix exemption is line-granular — a one-line `(cmd); IFS='|'` form matches step-1 via `;` but is dropped by step-2 because the line starts with `(`.**

**Finding:** AC-003 step-2 exempts subshell IFS assignments anchored to line-start (`^\s*\(`). A one-line form `(cmd); IFS='|'; foo` has the leading `(` triggering the step-2 exemption and dropping the entire line — but the trailing `IFS='|'` portion after the subshell close is a GLOBAL mutation that would persist after the subshell returns. The step-2 exemption is designed for `( IFS=x cmd )` (subshell-local), but it also exempts this trailing-global form because the exemption is applied at line granularity rather than at token granularity. Not present in any currently scanned script.

**Disposition:** ACCEPTED (prospective; not present in any current scan target; FREEZE DISCIPLINE). The line-granular exemption is a documented soundness boundary of the step-2 design. Hardening now would change the frozen artifact. Below the Drift Item threshold: exotic form; not present in any current script. FREEZE DISCIPLINE.

### O-2 (LOW — non-blocking, POLICY 13)

**ifs_step3_re command-prefix exemption is line-granular — `IFS='|'; foo; IFS=x read y` is dropped wholesale because the `IFS=x read` substring matches step-3, masking the leading global `IFS='|'`.**

**Finding:** AC-003 step-3 exempts read-context IFS assignments (`IFS=[^;|&]+ read`). A multi-statement line `IFS='|'; foo; IFS=x read y` is dropped wholesale because `IFS=x read` matches step-3, even though the leading `IFS='|'` on the same line is a global mutation that would execute before the read-context. The step-3 exemption operates on the entire line when ANY assignment+read subsequence appears; it does not require the read-context to be the FIRST IFS assignment on the line. This is an exotic multi-statement line style not present in any current script.

**Disposition:** ACCEPTED (prospective; exotic multi-statement style; not present in any current scan target; FREEZE DISCIPLINE). The line-granular exemption is a documented soundness boundary of the step-3 design. Hardening requires a token-granular or two-pass approach that would change the frozen artifact. FREEZE DISCIPLINE.

The gap is control-symmetry, not a soundness defect.

**Disposition:** ACCEPTED (control-completeness; no current false-positive risk per analytical verification; FREEZE DISCIPLINE). May fold into pre-PR polish burst for symmetry with jq twin. FREEZE DISCIPLINE for current 3-CLEAN convergence seal.
