### F-P6-001 — MEDIUM — Concurrent O_APPEND test non-discriminating (CLOSED same-session)

**POLICY:** POLICY 11 (positive-control gate discipline; tests must be discriminating)
**Location:** S-19.05 tests, AC-001 concurrent-write fixture
**Issue:** After the O_APPEND fix from pass-5 (commit 70c5a3f2), the concurrent-write test was written to spawn multiple writers and verify all events appeared in the sink. However, the test was non-discriminating: it would also PASS if the implementation used a global Mutex (serialized writes) rather than O_APPEND concurrent writes. A correct discrimination test must (a) verify that events from concurrent writers appear interleaved in the sink (not serialized), or (b) verify that no write uses a global Mutex, ensuring concurrent writes occur without serialization overhead. Without discrimination, the test cannot catch a regression back to Mutex-serialized writes.
**Fix:** implementer 1f568358: concurrent-write test hardened with non-serialization assertion (verifies no global Mutex acquired at write site via grep-based gate; event interleaving order verified by comparing writer-ID sequence in sink output against purely serialized order).
