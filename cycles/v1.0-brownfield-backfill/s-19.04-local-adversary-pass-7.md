### F7-1 — MEDIUM — Greedy-dot regex in lint gate (CLOSED same-session)

**POLICY:** POLICY 11 (positive-control gate; no greedy-pattern false-positives); TD-VSDD-060 (sibling-site sweep)
**Location:** S-19.04 AC-004 anchored-regex lint gate implementation
**Issue:** The lint gate's pattern-extraction regex used `.` (greedy dot, matches any character) in a position where a character class `[^(]` was required. The greedy dot would match TOML values that contain parentheses mid-string (e.g., a value like `^Edit(|Write)$`), allowing a malformed pattern to escape detection. The correct form requires a non-greedy or character-class-restricted extraction.
**Fix:** d2c08920 + story v1.18: lint gate regex corrected; positive-control test added for the greedy-dot false-negative case.
**Status:** CLOSED same-session — implementer d2c08920 + story v1.18
**Routing:** implementer + story-writer
