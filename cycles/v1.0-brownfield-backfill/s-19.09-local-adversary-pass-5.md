## Process-Gap Lesson Candidate

**2nd occurrence — Narrow-sweep-pattern residue (joins S-19.06 doc-sweep lesson family):**

When F-P4-001 was remediated, the verification gate used `grep -nE "670|744|lines? [0-9]+[–-][0-9]+"` — a pattern derived from the specific instance (`670–744` range form). This pattern correctly verified the seven-site fix but structurally could not detect adjacent occurrences of the same TD-VSDD-091 class (`line NN` singular forms) in the same document.

Root pattern: sweep gates that enumerate instance-specific values or forms rather than the general class of the prohibited pattern. Any instance-derived gate that clears the finding instance can leave the document with residual violations of the same rule class.

Prior occurrence (S-19.06 cascade): analogous narrow-sweep residue surfaced during the S-19.06 doc-sweep lesson. Two occurrences within a single wave confirm this is a systematic gap, not an isolated oversight.

**Codification target (at convergence):** "Remediation sweep grep patterns MUST target the GENERAL class of all file:line citation forms (e.g., `grep -nE "line [0-9]+"` for TD-VSDD-091 singular-form coverage) across the full non-historical document body. Instance-derived patterns (specific numbers, specific range forms) are insufficient and structurally cannot detect adjacent occurrences of the same violation class."
