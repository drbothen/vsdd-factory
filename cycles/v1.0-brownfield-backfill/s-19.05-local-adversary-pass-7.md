### F-P7-001 — MEDIUM — VSDD_ASYNC_DRAIN_WINDOW_MS gate needs cfg(any()) for test-path compilation (CLOSED same-session)

**POLICY:** BC-3.08.001 Invariant 5 (async drain window env var must be readable in all configurations); POLICY 11 (gate must compile under test-support cfg)
**Location:** vsdd_sink.rs VSDD_ASYNC_DRAIN_WINDOW_MS env-var read site
**Issue:** The `VSDD_ASYNC_DRAIN_WINDOW_MS` environment variable read in the sink was gated `#[cfg(not(test))]` without a corresponding `#[cfg(test)]` arm providing a mock value. Test binaries compiled with `#[cfg(test)]` therefore could not set the drain window via the env var, causing test isolation issues where the drain window defaulted to the production value in all test contexts. The correct pattern requires `#[cfg(any(not(test), feature = "test-support"))]` or an equivalent conditional that enables the env-var read in test-support builds.
**Fix:** b9dea7ce: VSDD_ASYNC_DRAIN_WINDOW_MS read site updated to `#[cfg(any(not(test), feature = "test-support"))]`; test-support feature added to Cargo.toml; AC-004 gate updated to verify cfg(any()) presence.
**Status:** CLOSED same-session — implementer b9dea7ce
**Routing:** implementer

### F-P7-002 — MEDIUM — SEC-003 tests non-discriminating: SINK_FILE injection untested (CLOSED same-session)

**POLICY:** POLICY 11 (positive-control gate; tests must discriminate correct from incorrect behavior); BC-3.08.001 security constraints (SEC-003: sink file must be writable only by dispatcher process)
**Location:** S-19.05 SEC-003 test fixtures
**Issue:** The SEC-003 tests verified that the sink file permission bits were set correctly after creation, but the tests were non-discriminating for the injection path: they did not verify that the `VSDD_SINK_FILE` path could NOT be injected with a path-traversal string (e.g., `../../etc/cron.d/evil`). A correct SEC-003 test requires (a) a positive-control asserting that a benign path is accepted, and (b) a negative-control asserting that a path-traversal or out-of-.factory/ path is rejected.
**Fix:** 965f4e32: SEC-003 tests extended with path-traversal negative-control fixture (verifies injection rejected; exit non-zero on path outside .factory/).
