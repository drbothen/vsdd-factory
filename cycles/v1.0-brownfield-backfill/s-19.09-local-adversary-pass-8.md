The code is correct; the spec is the deficient artifact.

**Code adjudication:** CORRECT. D22 implementation persists `timestamp` on both sync and async plugin.completed paths. No code change required.

**Spec fix required:**
1. BC-3.08.001 Event 6: add `timestamp` to Mandatory-fields list; add it to the wire example (matching Events 1-5 structure). Version bump v1.23→v1.24.
2. AC-009: replace citation "§Common Fields mandatory timestamp" with a precise anchor that names Event 6 §Mandatory-fields explicitly (after BC v1.24 lands).
