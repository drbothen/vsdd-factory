# AC-004 Evidence: All tool= Entries Fully Anchored (Both Ends)

**Story:** S-19.04 — Registry/bundle hygiene: orphan WASM removal + tool-filter regex anchoring convention + lint check
**AC:** AC-004 — All existing `tool =` entries use fully-anchored patterns (leading `^` AND trailing `$`) per D-a table; positive-scope verification that verify-factory-lock still fires on MultiEdit

## Claim

Every `tool =` entry in `hooks-registry.toml` that targets specific tools uses
a fully-anchored pattern (both `^` leading AND `$` trailing before the closing
quote), or carries an `# intent:` inline comment. Prefix-only patterns like
`tool = "^Bash"` are violations. The gate produces zero output (empty result)
against the live registry.

## Evidence

### Main gate: zero non-fully-anchored entries (live registry)

```
$ result=$(grep -E '^tool = ' plugins/vsdd-factory/hooks-registry.toml \
    | grep -vE 'tool = ["'"'"']\^[^"'"'"']*\$["'"'"']' \
    | grep -vi '# *intent:' || true)
$ [ -z "$result" ] && echo "PASS: zero non-fully-anchored entries without intent comments (empty output)"
PASS: zero non-fully-anchored entries without intent comments (empty output — all entries pass)
```

Exit 0 — all `tool =` lines in `hooks-registry.toml` have both leading `^` and
trailing `$` before the closing quote.

### Negative fixture: prefix-only anchor flagged (F6-1)

```
# prefix-only-anchor.toml contains: tool = "^Bash"  (^ without $)
$ result=$(grep -E '^tool = ' plugins/vsdd-factory/tests/fixtures/registry-tool-filter/prefix-only-anchor.toml \
    | grep -vE 'tool = ["'"'"']\^[^"'"'"']*\$["'"'"']' \
    | grep -vi '# *intent:' || true)
$ echo "$result"
tool = "^Bash"
```

PASS (negative fixture FLAGGED as violation) — `tool = "^Bash"` (leading `^`,
no trailing `$`) is correctly identified as a violation. The preamble counter-example
holds: `^Bash` regex-SEARCH still matches `BashAsync`.

### Negative fixture: comment-injection flagged (F7-1)

```
# comment-inject.toml contains: tool = "^Edit" # note "$"
$ result=$(grep -E '^tool = ' plugins/vsdd-factory/tests/fixtures/registry-tool-filter/comment-inject.toml \
```

PASS (negative fixture FLAGGED as violation) — the `$` in the comment after the
closing quote does NOT rescue the entry; the `[^"']*` pattern in the gate correctly
rejects it. Greedy-dot bypass class is closed.

### Positive-scope verification: verify-factory-lock pattern is fully anchored

The bats test T-005 confirms verify-factory-lock's pattern `^(Edit|Write|MultiEdit|Agent)$`
is classified as fully anchored and includes MultiEdit in scope (see AC-005 evidence).
