## Claim

`crates/factory-dispatcher/tests/bundle_orphan_check.rs` implements dual-registry
orphan detection checking both `hooks-registry.toml` AND `resolvers-registry.toml`.
Four fixture sub-tests verify: (a) resolvers-only WASM is non-orphan; (b) hooks-only
WASM is non-orphan; (c) neither-registry WASM is orphan (`ORPHAN: <name>`); (d)
negative-control — detection with only hooks-registry data classifies resolvers-only
WASM as orphan (confirms dual-registry check is load-bearing, not advisory).
T-009 is the hermetic tracked-bundle standing-GREEN gate via `git ls-files`.

### Why T-009 uses git ls-files (not fs::read_dir)

`hook-plugins/` is gitignored. A local `cargo build --target wasm32-wasip1` deposits
untracked underscore-named stubs there. `git ls-files` sees only the committed set,
making T-009 contamination-resistant on any post-build dev machine. The test catches
future regressions where an unreferenced WASM is accidentally committed.
