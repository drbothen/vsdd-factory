# AC-003 Evidence: Merge-Strategy Enforcement via enforce-merge-strategy.sh + Step 8 Wiring

**Story:** S-19.01 — pr-manager hardening: READY verdict HEAD-SHA pinning + release-PR merge-strategy guard + shell-dialect simulation discipline
**AC:** AC-003 (traces to BC-5.42.001 PC-3, Invariant 3, Invariant 6, Invariant 7)

## Claim

`enforce-merge-strategy.sh` is the **sole gateway** for all `gh pr merge`
invocations. Direct `gh pr merge` calls bypassing this wrapper are a protocol
violation (ADR-030 §Decision 3). Invocation form:
`enforce-merge-strategy.sh <pr_number> [--merge|--squash|--rebase] [residual-args...]`

Strategy is positionally owned as `$2`; residual args `"${@:3}"` (e.g.,
`--delete-branch`) are forwarded verbatim after the resolved strategy. Before
forwarding, residual args are scanned against a deny-list: any argument matching
a strategy or admin flag (`--squash`, `--merge`, `--rebase`, `--admin`, `-s/-m/-r/-A`
in any form including `=`-fused and combined-short-cluster) exits 1 with
`STRATEGY_SMUGGLING_FORBIDDEN`. When the source branch matches `^release/v`,
the wrapper forces `--merge`; `--squash` or `--rebase` on a release branch exits
1 with `RELEASE_PR_SQUASH_FORBIDDEN`.

**T-005** (negative control — squash on release branch): Mocks `gh pr view --json
headRefName` returning `release/v1.0.0-rc.23`. Invokes `enforce-merge-strategy.sh
10 --squash`. Asserts exit 1, `RELEASE_PR_SQUASH_FORBIDDEN` in stderr, branch name
in message, and that `gh pr merge` was NOT called (verified via sentinel file).
BC-5.42.001 Invariant 3: no GitHub API call before exit.

**T-006** (positive control — merge on release branch): Same branch, `--merge`
flag. Asserts exit 0 (merge proceeds). `gh pr merge` is invoked via mock.

**T-007** (positive control — squash on non-release): Feature branch
`feature/S-19.01`, `--squash`. Asserts exit 0 (delegated unchanged). Non-release
branches pass the caller-supplied flag through.

**T-011** (TV3 — rebase on release branch): `--rebase` is forbidden on `release/v*`
same as `--squash`. Asserts exit 1 + `RELEASE_PR_SQUASH_FORBIDDEN`.

**T-012** (EC-005 — default injection): No explicit flag on `release/v*` branch.
Asserts exit 0 and that `gh pr merge` received `--merge` flag (recorded via
sentinel file). Verifies the default-injection path is not vacuous.

**T-015** (canonical format gate): Exact BC-5.42.001 §Description c wording
verbatim, including the mandatory `per RELEASING.md` anchor:
`RELEASE_PR_SQUASH_FORBIDDEN: branch release/v1.0.0-rc.23 requires --merge per RELEASING.md`

**T-022** (sole-gateway wiring gate — F-P7-001): Inspects `pr-manager.md` for
direct `gh pr merge` calls bypassing the wrapper. Asserts zero direct `gh pr merge`
occurrences outside the `enforce-merge-strategy.sh` invocations. Step 8-pre-A
and Step 8-pre-B in `pr-manager.md` both route via the wrapper.

**T-023** (residual pass-through — `--delete-branch`): Passes `--delete-branch`
as a residual arg on a feature branch. Asserts `gh pr merge` is called with
`--delete-branch` forwarded verbatim (deny-list positive: `--delete-branch` is not
a strategy or admin flag).

**T-024** (deny-list — `--squash` in residual position): Passes `--merge 10 --squash`
so `--squash` arrives as `$3` (residual). Asserts exit 1 +
`STRATEGY_SMUGGLING_FORBIDDEN: residual arg --squash is a strategy or admin flag`.
Deny-list fires before any branch check.

**T-025** (deny-list — `--admin` in residual): `--admin` in residual position.
Asserts exit 1 + `STRATEGY_SMUGGLING_FORBIDDEN`.

**T-026** (deny-list — combined short cluster `-sd`): `-s` (squash short) combined
with `-d` (delete-branch short) → exit 1 + `STRATEGY_SMUGGLING_FORBIDDEN`.
The deny-list matches `-[smrA]*` pattern (starts with a strategy char).

**T-027** (deny-list positive — `--delete-branch` allowed): `--delete-branch` in
residual is not a strategy flag; delegated unchanged. Exit 0.

**T-028** (release + `--delete-branch`): `release/v*` branch with `--merge
--delete-branch`. Both strategy injection and residual forwarding work together.
Asserts exit 0 and both flags present in `gh pr merge` invocation.

**T-029/T-030** (F-P8-003 — `--admin`/`-A` as `$2` strategy slot): Passing
`--admin` or `-A` in the primary strategy position ($2) is rejected with
`INVALID_STRATEGY` before any gh API call. These are privilege-escalation flags
that bypass merge protections in gh; treating them as valid merge strategies would
be a security hole.

**T-031** (positive regression guard for F-P8-003): After adding `--admin`/`-A`
rejection, verifies `--merge` as `$2` still works on a feature branch (exit 0).
Guards against over-broad rejection.
