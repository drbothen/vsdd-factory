=== Root cause closed (rc.22 smoke FINDING-2) ===

path_allowed() returns false → prepare() emits internal.capability_denied reason=path_not_allowed
→ plugin receives CAPABILITY_DENIED → plugin emits warn log "capability configuration error" →
T-008 would FAIL (cap_denied_count > 0).

Post-fix behavior: absent wave-state.yaml → rejoin algorithm → path_allowed() returns true →
read_bounded() fails to open → ReadErr::NotFound → emits internal.file_not_found →
returns codes::NOT_FOUND (-5) → plugin receives NOT_FOUND → plugin exits silently (Continue) →
zero capability_denied events → T-008 PASSES.
