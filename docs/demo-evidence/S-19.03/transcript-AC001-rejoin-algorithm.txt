=== Root cause closed ===

The old path_allowed() called resolved.canonicalize() directly. For absent files, canonicalize()
returns Err, and path_allowed() returned false unconditionally, emitting capability_denied
reason=path_not_allowed even when the path WAS in the allowlist. The rejoin algorithm in
resolve_path_for_allowlist (shared path_util.rs) correctly handles absent-file cases by walking
to the deepest existing ancestor, rejoining the non-existent tail, and then checking prefix
membership — separating "file absent but path allowed" from "path genuinely not allowed."
